# MediaVault Frontend

## 概要
MediaVaultのフロントエンド部分のPRD。映画・アニメ・漫画・小説・ドラマ・ゲーム・論文/文献・書籍などのメタデータを一元管理するセルフホスト型アプリケーションのうち、ユーザーがコレクションを閲覧・整理・カスタマイズするためのUIを担う。
全体構想は[ルートPRD](../../docs/PRD.md)を参照。バックエンド側は[backend/docs/PRD.md](../../backend/docs/PRD.md)を参照。

## 技術スタック
| 要素 | 技術 |
|------|------|
| フロントエンド | React + TypeScript |

## 共通機能（UI）
| 機能 | 概要 |
|---|---|
| 作品検索・追加（API） | 外部APIをタイトル等で検索し、検索結果一覧からコレクションに追加できる画面 |
| 作品手動追加 | API検索を使わず、フォーム入力でアイテムを新規作成できる画面 |
| 作品編集・削除 | 既存アイテムの全項目を編集・削除できる画面 |
| 一覧・絞り込み | media_type・タグ・カテゴリ・お気に入り・status等で一覧をフィルタリングできる画面 |
| タグ/カテゴリ管理 | タグ・カテゴリの作成・付与・削除を行うUI |
| マイリスト管理 | 任意名称のリストを作成し、アイテムを追加・削除できるUI |
| 関連付け | 他メディアのアイテムを引用・関連として紐付けるUI |
| リンク/ファイル/トレーラー管理 | 配信サイトリンク・ファイルパス・トレーラーURLを追加・編集・削除するUI |
| 視聴・読了記録 | statusと観賞/読了日（consumed_date）を更新するUI |
| スタッフ管理 | スタッフ（監督・声優・著者など）の追加・役割付与・作品への紐付けを行うUI |

## メディア別機能（UI）
| メディア | 機能 |
|---|---|
| アニメ・ドラマ | シーズン単位で話数（エピソード）情報を登録・編集・一覧表示する画面 |
| 映画 | 章単位のグループ表示（任意） |
| 漫画・小説 | 巻単位のグループ表示・管理画面 |
| ゲーム | DLC/拡張パックを本体作品に紐付けて表示する画面 |
| 学術書・専門書 | 著者・出版社・ISBNなど学術書特有の属性を入力・表示する画面 |
| 論文・文献 | DOI・掲載誌・巻号・ページ等の学術メタデータを入力・表示する画面 |

## 画面構成（草案）
| 画面 | 概要 |
|---|---|
| 全体一覧画面 | コレクション全体をカード/リスト表示し、media_type・タグ・カテゴリ・お気に入り・statusで絞り込み。アプリのホーム |
| 一覧画面（一般メディア） | アニメ・映画・小説・ドラマ・漫画・ゲームに絞った一覧 |
| 一覧画面（学術書・専門書） | 学術書・専門書に絞った一覧 |
| 一覧画面（論文・文献） | 論文・文献に絞った一覧 |
| 詳細画面 | アイテムの全属性、シーズン/話数・巻・DLC等のメディア別構成、関連付け、リンク/ファイル/トレーラー、スタッフ情報を表示 |
| 検索・追加画面（一般メディア） | アニメ・映画・小説・ドラマ・漫画・ゲームを対象に、外部API検索結果一覧から選んでコレクションに追加 |
| 検索・追加画面（学術書・専門書） | 著者・出版社・ISBN等の学術書特有項目に対応した外部API検索・追加画面 |
| 検索・追加画面（論文・文献） | DOI・掲載誌・巻号等の学術メタデータに対応した外部API検索・追加画面 |
| 手動追加・編集画面（一般メディア） | アニメ・映画・小説・ドラマ・漫画・ゲーム向けのフォーム入力で新規作成・編集 |
| 手動追加・編集画面（学術書・専門書） | 著者・出版社・ISBN等の学術書特有項目を入力するフォーム |
| 手動追加・編集画面（論文・文献） | DOI・掲載誌・巻号・ページ等の学術メタデータを入力するフォーム |
| マイリスト画面 | リスト一覧・作成・各リストの中身管理 |
| タグ/カテゴリ管理画面 | タグ・カテゴリの作成・編集・削除 |
| スタッフ管理画面 | スタッフ一覧・追加・役割付与・作品紐付け |
| 設定画面 | エクスポート・インポート・APIキー管理をまとめたページ（タブ等で分割） |

画面遷移の大枠：全体一覧画面、またはメディアグループ別一覧画面を起点に詳細・検索追加・手動追加へ遷移。検索追加・手動追加・グループ別一覧はメディアグループ（一般メディア／学術書・専門書／論文・文献）ごとに別画面へ遷移する。タグ/カテゴリ管理・マイリスト・スタッフ管理・設定はグローバルナビからアクセス。

## 設定画面
| 機能 | 概要 |
|---|---|
| エクスポート | コレクションをObsidian/Notion向け形式で出力するUI |
| インポート | ブクログ(csv)・Steamライブラリからアイテムを一括取込するUI |
| APIキー管理 | 各外部APIのキーを登録・更新する設定画面 |

## やらなくていいこと
