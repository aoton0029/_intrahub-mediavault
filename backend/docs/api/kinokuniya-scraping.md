# 紀伊国屋スクレイピング
紀伊国屋のサイトから、書籍の情報をスクレイピングするためのAPIです。

# API設計

## 基本方針
- ベースURL: `https://www.kinokuniya.co.jp/f/`
- レスポンス形式: HTML

## エンドポイント
| Method | Path | 説明 | 認証 |
|--------|------|------|------|
| GET | /dsg-01-{ISBN} | 書籍の検索（13桁のISBN指定） | 不要 |

## GET /dsg-01-{ISBN}
### リクエスト
```
GET https://www.kinokuniya.co.jp/f/dsg-01-{ISBN}
```

### パラメーター
- `{ISBN}`: 13桁のISBNコード（必須）
### リクエスト例
```bash
curl "https://www.kinokuniya.co.jp/f/dsg-01-9784150125066"
```
