設計書 `docs/frontend/design/01_home.md` 中の【要確認】項目、および実装中に新たに生じた未確定事項を記録する。Codexは実装をブロックする判断が必要な場合、ここに追記してからClaudeのレビューを待つ。ブロッキングでない場合は妥当な仮決定を行いメモを残した上で先に進んでよい。

## 一覧

### 1. 統計集計API未定義
- 出典: 設計書 §6
- 論点: `HomeStats`（総件数・進行中・視聴済み・お気に入り件数）を返す専用の集計APIが未定義。フロントで複数回`GET /items`をフェッチして集計する暫定実装か、バックエンドに集計エンドポイント追加が必要
- 選択肢: A) フロントで`limit`を大きくして複数回フェッチ・集計する暫定実装にする B) バックエンドに`GET /items/stats`等の集計エンドポイント追加を依頼する
- 仮決定: A（暫定実装）。バックエンド側の対応が決まるまではフロント側で件数集計を行う
- 状態: [ ] 未決定

### 2. `sort`パラメータ未実装
- 出典: 設計書 §6
- 論点: 「最近追加した作品」は作成日時降順を期待するが、`GET /items`に`sort`パラメータが無いため既定の並びに暗黙的に依存している
- 状態: [ ] 未決定（バックエンド仕様確定待ち）
