# TASK-0007: グローバルナビゲーション実装 要件定義書

## 1. 機能の概要（EARS要件定義書・設計文書ベース）

- 🔵 サイドバー形式のグローバルナビゲーションコンポーネントを実装する機能。全体一覧・メディアグループ別3一覧・マイリスト・タグ/カテゴリ管理・スタッフ管理・設定の各画面への遷移リンクを提供する。
- 🔵 解決する問題: architecture.md「画面構成とルーティング」に定義された「グローバルナビ（サイドバー）からマイリスト・タグ/カテゴリ・スタッフ・設定へアクセスする」という導線を実現する。ナビゲーションがないと利用者が主要画面（マイリスト等）へ到達できない。
- 🔵 想定ユーザー: MediaVaultの単一ユーザー（note.md「単一ユーザー前提。認証・ログインUIは持たない」）。
- 🔵 システム内での位置づけ: `RootLayout`（TASK-0003で実装済み、`src/pages/RootLayout.tsx`）内で`<Outlet />`と組み合わせて全ページ共通の左サイドバーとして表示される。Phase 2以降の全pagesがこのナビゲーションを前提として画面遷移する。
- **参照したEARS要件**: REQ-004（3メディアグループ別一覧画面）
- **参照した設計文書**: architecture.md「画面構成とルーティング」、TASK-0003（RootLayout構成）

## 2. 入力・出力の仕様

- 🔵 入力: なし（外部からのpropsを受け取らない静的なナビゲーション構成）。現在のルートパスは`react-router-dom`の`NavLink`が内部的に`useLocation`相当の仕組みで取得する。
- 🔵 出力: ナビゲーションリンク一覧のレンダリング（`<nav>`内に`<NavLink>`要素群）。クリック時はReact Routerの`navigate`によりURLが変化し、対応するpageコンポーネントが`RootLayout`の`<Outlet />`にレンダリングされる。
- 🔵 ナビゲーション項目とパスの対応（TASK-0007.mdより確定）:

| label | to |
|---|---|
| 全体一覧 | `/` |
| 一般メディア | `/collections/general` |
| 学術書・専門書 | `/collections/academic` |
| 論文・文献 | `/collections/paper` |
| マイリスト | `/mylists` |
| タグ/カテゴリ | `/tags-categories` |
| スタッフ | `/staff` |
| 設定 | `/settings` |

- 🟡 リンクラベル文言は設計文書に直接の指定がないため、architecture.mdの画面名称表記から妥当な推測（TASK-0007.md記載のまま採用）。
- **参照したEARS要件**: REQ-004
- **参照した設計文書**: TASK-0007.md「ナビゲーション構成」、routes.tsx（TASK-0003実装済み、`/`, `/collections/general`, `/collections/academic`, `/collections/paper`, `/mylists`, `/tags-categories`, `/staff`, `/settings`の各パスが定義済みであることを確認）

## 3. 制約条件

- 🔵 React Router v7の`<NavLink>`（または`<Link>`）を使用すること（完了条件）。
- 🔵 `NavLink`の`className`関数（`isActive`引数）でアクティブ状態を視覚的に識別できるようにすること（完了条件、TASK-0007.md実装詳細）。
- 🟡 配置場所は`src/components/common/Sidebar.tsx`を基本方針とする（architecture.mdのコンポーネント粒度方針「common/＝複数画面で再利用する独自コンポーネント」からの妥当な推測）。
- 🟡 アクティブ状態の視覚仕様（色・スタイル等の具体値）は設計文書に明記がないため、Tailwind CSS + 既存デザイントークン（TASK-0002で設定済みの`--accent`等）を用いた妥当な実装とする。
- 🔵 単体テストがすべてパスすること（完了条件）。テストはReact Testing Library + `MemoryRouter`を使用する。
- **参照したEARS要件**: なし（非機能要件としての明記はないが、完了条件として明記）
- **参照した設計文書**: TASK-0007.md「完了条件」「React Router v7との統合」「配置場所」

## 4. 想定される使用例

- 🔵 基本パターン: ユーザーが画面左のサイドバーから「マイリスト」をクリックすると`/mylists`へ遷移し、`MyListsPage`が表示される。
- 🔵 アクティブ状態表示: 現在`/staff`を閲覧中の場合、サイドバーの「スタッフ」リンクに`active`クラス（または同等のスタイル）が付与され、他のリンクと視覚的に区別される。
- 🟡 エッジケース: 動的パラメータを含むルート（`/items/:id`等）はサイドバーの対象外（ナビゲーション項目に含まれない、TASK-0007.mdのnavItems一覧に該当パスなし）。
- **参照したEARS要件**: なし（TASK-0007.md単体テスト要件のテストケース1〜3に基づく）
- **参照した設計文書**: TASK-0007.md「単体テスト要件」
