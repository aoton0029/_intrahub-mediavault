## タスク概要

MediaVault-api の `relation_type` PostgreSQL ENUM を現行の2値（`reference` / `dlc`）から6値へ拡張する。MCP の `relate_items` ツール（TASK-0021）が要件どおり動作するための前提となる。

あわせて、`item_id` → `related_item_id` の向きが種別ごとに何を意味するかを API 仕様書に定義する。

## 実装詳細

### 1. マイグレーションの追加 🔵

**信頼性**: 🔵 *`migrations/20260623000001_init_schema.up.sql:21` の現行定義より*

PostgreSQL の ENUM は値の削除ができないため、`ALTER TYPE ... ADD VALUE` で追加のみ行う。

**実装ファイル**: `backend/mediavault-api/migrations/{timestamp}_extend_relation_type.up.sql`

```sql
ALTER TYPE relation_type ADD VALUE IF NOT EXISTS 'adaptation';
ALTER TYPE relation_type ADD VALUE IF NOT EXISTS 'sequel';
ALTER TYPE relation_type ADD VALUE IF NOT EXISTS 'prequel';
ALTER TYPE relation_type ADD VALUE IF NOT EXISTS 'spinoff';
```

**down マイグレーション** 🟡

**信頼性**: 🟡 *PostgreSQL の制約から導かれる実装上の判断*

ENUM 値の削除は直接できないため、down では型の再作成（新型作成 → カラム変換 → 旧型削除）が必要になる。追加値を使ったデータが存在する場合は down が失敗する旨をコメントで明記する。

### 2. Rust enum の拡張 🔵

**信頼性**: 🔵 *`backend/mediavault-api/src/models/item_relation.rs:14` の `#[sqlx(type_name = "relation_type", rename_all = "lowercase")]` より*

**実装ファイル**: `backend/mediavault-api/src/models/item_relation.rs`

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, sqlx::Type)]
#[sqlx(type_name = "relation_type", rename_all = "lowercase")]
#[serde(rename_all = "lowercase")]
pub enum RelationType {
    Adaptation,
    Sequel,
    Prequel,
    Spinoff,
    Dlc,
    Reference,
}
```

`rename_all = "lowercase"` により、すべて単一語の値であるため ENUM 文字列と一致する。

### 3. バックアップ機能への影響確認 🟡

**信頼性**: 🟡 *`src/models/backup.rs:137` に `relation_type: RelationType` が存在することから導かれる*

`POST /backup/export` / `POST /backup/import` が `RelationType` を含むため、新しい値がバックアップの往復で失われないことを確認する。`schema_version` の更新が必要かを判断する。

### 4. API仕様書への向きの定義 🔵

**信頼性**: 🔵 *REQ-072・[mcp-tools.md](../design/mcp-tools.md) の関係種別表より*

**実装ファイル**: `docs/backend/mediavault-api/item-relations.md`

| 値 | `item_id`（起点） | `related_item_id`（終点） |
|---|---|---|
| `adaptation` | 原作 | 映像化・翻案作品 |
| `sequel` | 前作 | 続編 |
| `prequel` | 後の作品 | 前日譚 |
| `spinoff` | 本編 | スピンオフ |
| `dlc` | 本編 | DLC・追加コンテンツ |
| `reference` | 引用元 | 引用先 |
