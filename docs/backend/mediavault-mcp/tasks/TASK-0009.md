## 実装詳細

### 1. Outcome と ToolError 🔵

**信頼性**: 🔵 *設計決定 D-01・[interfaces.rs](../design/interfaces.rs) より*

**実装ファイル**: `backend/mediavault-mcp/src/result/outcome.rs`

```rust
#[derive(Serialize, JsonSchema)]
#[serde(rename_all = "snake_case")]
pub enum Outcome { Success, Partial, Error, Ambiguous, NotFound }

#[derive(Serialize, JsonSchema)]
pub struct ToolError { pub code: String, pub message: String, pub retriable: bool }
```

`McpErrorCode`（`MCP_API_UNREACHABLE` / `MCP_INTERNAL_AUTH_FAILED` / `MCP_INVALID_ARGUMENT` / `MCP_NAME_NOT_RESOLVED`）も同ファイルに定義する 🟡 *[interfaces.rs](../design/interfaces.rs) の命名規約は設計上の決定*

### 2. ApiClientError → ToolError の変換 🔵

**信頼性**: 🔵 *[dataflow.md](../design/dataflow.md) エラーハンドリングフローより*

**実装ファイル**: `backend/mediavault-mcp/src/result/outcome.rs`

| `ApiClientError` | `Outcome` | `code` | `retriable` |
|---|---|---|---|
| `Connection` | `Error` | `MCP_API_UNREACHABLE` | true |
| `Auth` | `Error` | `MCP_INTERNAL_AUTH_FAILED` | false |
| `Api { status: 404 }` | `NotFound` | apiの値を保持 | false |
| `Api { status: 400/422 }` | `Error` | apiの値を保持 | false |
| `Api { status: 5xx }` | `Error` | apiの値を保持 | true |
| `Decode` | `Error` | `MCP_DECODE_FAILED` | false 🟡 |

**409 の扱いは変換関数に含めない** 🔵

**信頼性**: 🔵 *[dataflow.md](../design/dataflow.md)「冪等化する409の一覧」より*

`ITEM_ALREADY_IMPORTED` / `DUPLICATE_RELATION` / `DUPLICATE_STREAMING_LINK` は成功へ読み替えるが、その判断は各ツールの Service 層が行う。共通変換では 409 を通常のエラーとして扱い、必要なツールが個別に握る。

### 3. OperationResult 🔵

**信頼性**: 🔵 *REQ-114・[interfaces.rs](../design/interfaces.rs) より*

**実装ファイル**: `backend/mediavault-mcp/src/result/operation.rs`

`Applied` / `AlreadyApplied` / `NotResolved` / `Failed` / `Skipped` の5バリアント。`#[serde(tag = "result", rename_all = "snake_case")]`。

**集約ヘルパ** 🟡

**信頼性**: 🟡 *複数ツールで同じ集約が必要になることから導かれる実装上の判断*

`Vec<OperationResult>` 群から全体の `Outcome` を決める関数を用意する。

```
すべて Applied / AlreadyApplied           → Success
1件以上 Failed / NotResolved / Skipped あり、かつ成功も1件以上 → Partial
すべて Failed / NotResolved               → Error
```

### 4. Section<T> 🔵

**信頼性**: 🔵 *REQ-021・EDGE-105・設計決定 D-05 より*

**実装ファイル**: `backend/mediavault-mcp/src/result/mod.rs`

```rust
#[serde(tag = "state", rename_all = "snake_case")]
pub enum Section<T> { Loaded { items: Vec<T> }, Empty, Failed { error: ToolError } }
```

`Result<Vec<T>, ApiClientError>` から `Section<T>` を作る変換を用意する。空の `Vec` は `Empty` に落とす（「未登録」の表現）🔵
