## タスク概要

`backend/mediavault-mcp` クレートを新規作成し、既存の Cargo workspace へ統合する。`rmcp` 3.1系の依存を追加し、最小の axum サーバーが起動することを確認する。

`rmcp` は本プロジェクトで初めて使う SDK であるため、本タスクで API 形状（`StreamableHttpService` の axum 統合方法、`#[tool]` マクロの記法）を実地で確認し、以降のタスクの前提を固める。

## 注意事項

- **`rmcp` のバージョンは実装着手時に crates.io で最新安定版を再確認する**。本タスク文書作成時点（2026-08-07）の最新は 3.1.1 🔵 *[tech-stack.md](../tech-stack.md) より*
- feature 名（`transport-streamable-http-server` など）は 3.1 系の実際の定義と異なる可能性がある。`cargo add rmcp --features ...` で失敗したら SDK のドキュメントを確認する 🟡
- `schemars` のバージョンは `rmcp` が要求するものに合わせる。不整合だと `JsonSchema` の derive が効かない 🟡
- **CLAUDE.md の指示**: `rmcp` は本プロジェクトで初めて使う不慣れな SDK であるため、実装前に `unknowns-field-guide` スキルを読むこと
