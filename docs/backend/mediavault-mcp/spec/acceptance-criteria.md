## REQ-010 / REQ-011 / REQ-012 / REQ-013 / REQ-014: search_library 🔵

**信頼性**: 🔵 *PRD §5 US-01・`GET /api/v1/items` 仕様・ヒアリング2026-08-07より*

### Given（前提条件）
- MediaVault-api モックが `GET /api/v1/items` に応答する
- MCP サーバーが認証済みセッションで起動している

### When（実行条件）
- `search_library` をタイトル・メディア種別・状態・タグ名・カテゴリ名・お気に入りの各条件で呼び出す

### Then（期待結果）
- 候補一覧と該当件数が構造化されて返る
- 各候補に ID・タイトル・メディア種別・公開年・状態・タグが含まれる

### テストケース

#### 正常系
- [ ] **TC-010-01**: タイトル部分一致で1件ヒット 🔵
  - **入力**: `{ "title": "作品A" }`
  - **期待結果**: 候補1件、`total_count: 1`、候補に `item_id` が含まれる
- [ ] **TC-010-02**: 同名作品が3件ヒットし、区別できる情報が返る 🔵
  - **入力**: `{ "title": "同名作" }`
  - **期待結果**: 候補3件、それぞれ `media_type` / `release_date` / `status` が異なる値で返る
- [ ] **TC-011-01**: 原題での検索がヒットする 🔵
  - **入力**: `{ "title": "Original Title" }`（本題は日本語）
  - **期待結果**: 該当 Item が候補に含まれる
- [ ] **TC-011-02**: 別名（`details.alternative_titles`）での検索がヒットする 🔵
  - **入力**: `{ "title": "略称" }`
  - **期待結果**: 該当 Item が候補に含まれる
- [ ] **TC-010-03**: タグ名指定がタグIDへ解決されて検索される 🔵
  - **入力**: `{ "tag": "積読" }`
  - **期待結果**: `GET /tags` で解決した ID が `GET /items?tag_id=` に渡る
- [ ] **TC-014-01**: 0件時にローカル検索であることが明示される 🔵
  - **入力**: `{ "title": "存在しない作品" }`
  - **期待結果**: `total_count: 0`、結果に「MediaVault内に該当なし」を示す構造が含まれ、外部検索結果と混同されない

#### 異常系
- [ ] **TC-010-E01**: MediaVault-api が接続不能 🔵
  - **入力**: モックを停止した状態で呼び出す
  - **期待結果**: `ConnectionError` として返り、`ApiError` と区別できる
- [ ] **TC-010-E02**: 不正な `media_type` 指定 🔵
  - **入力**: `{ "media_type": "invalid" }`
  - **期待結果**: バリデーションエラー。API を呼ばない、または API の 400 をそのまま返す

#### 境界値
- [ ] **TC-013-B01**: `limit` に51を指定 🟡
  - **入力**: `{ "limit": 51 }`
  - **期待結果**: 50に丸められる、またはバリデーションエラー（設計で確定：EDGE-101）
- [ ] **TC-013-B02**: `limit` 未指定時の既定値 🔵
  - **期待結果**: 20件で返る
- [ ] **TC-010-B01**: 検索語が空白のみ 🟡
  - **入力**: `{ "title": "   " }`
  - **期待結果**: バリデーションエラー。全件返却しない
