## REQ-001/002: 全体一覧・絞り込み 🔵

**信頼性**: 🔵 *frontend/PRD.md・backend GET /items より*

### Given（前提条件）
- アイテムが複数件、異なるmedia_type・タグ・status・お気に入りフラグで登録済み

### When（実行条件）
- 全体一覧画面を開き、絞り込みUIでmedia_type=animeかつお気に入り=trueを選択する

### Then（期待結果）
- `GET /items?media_type=anime&is_favorite=true&page=1&limit=20` が呼ばれ、条件に合致するアイテムのみカード表示される

### テストケース

#### 正常系
- [ ] **TC-001-01**: 絞り込み条件なしで全アイテムが表示される 🔵
- [ ] **TC-001-02**: media_type単独で絞り込める 🔵
- [ ] **TC-001-03**: 複数条件（media_type + favorite + tag）を組み合わせて絞り込める 🔵

#### 異常系
- [ ] **TC-001-E01**: 該当0件の場合、空状態メッセージとアイテム追加への導線が表示される（EDGE-101） 🟡

#### 境界値
- [ ] **TC-001-B01**: アイテム数がlimit（20件）を超える場合、ページングが機能する 🔵

## REQ-005/203: 外部API検索・追加 🔵

**信頼性**: 🔵 *frontend/PRD.md・backend GET /items/search・POST /items/import より*

### Given（前提条件）
- 対象media_typeのAPIキーが設定済み

### When（実行条件）
- 検索・追加画面でタイトルを入力し検索を実行、結果から1件選んで「追加」を押す

### Then（期待結果）
- `GET /items/search` の結果一覧が表示され、選択後 `POST /items/import` で201が返り、一覧に新規アイテムが反映される

### テストケース

#### 正常系
- [ ] **TC-005-01**: 検索語を入力し結果一覧が表示される 🔵
- [ ] **TC-005-02**: 結果を選択してコレクションに追加できる 🔵

#### 異常系
- [ ] **TC-005-E01**: APIキー未設定（`API_KEY_NOT_CONFIGURED`, 422）の場合、エラーメッセージと手動追加への導線が表示される 🔵
- [ ] **TC-005-E02**: 外部APIタイムアウト（`EXTERNAL_API_TIMEOUT`, 502）の場合、再試行ボタンとエラーメッセージが表示される 🔵

#### 境界値
- [ ] **TC-005-B01**: 検索語が空の場合、検索ボタンが無効化される、またはバリデーションエラーが表示される 🟡

## REQ-006/007: 手動追加・編集・削除 🔵

**信頼性**: 🔵 *frontend/PRD.md・backend POST/PATCH/DELETE /items より*

### Given（前提条件）
- 手動追加・編集画面を開いている

### When（実行条件）
- 必須項目（media_type, title）を入力して保存する

### Then（期待結果）
- `POST /items`（新規）または `PATCH /items/:id`（編集）が呼ばれ、成功後に詳細画面へ遷移する

### テストケース

#### 正常系
- [ ] **TC-006-01**: 必須項目を入力して新規アイテムを作成できる 🔵
- [ ] **TC-006-02**: 既存アイテムの項目を変更し保存できる 🔵
- [ ] **TC-006-03**: 削除確認ダイアログ経由でアイテムを削除できる 🔵

#### 異常系
- [ ] **TC-006-E01**: media_typeが不正な場合 `VALIDATION_ERROR`（400）を受け、フィールド近傍にエラーメッセージが表示される（NFR-201） 🟡
- [ ] **TC-006-E02**: 存在しないIDの編集で `ITEM_NOT_FOUND`（404）の場合、一覧へのリダイレクトとエラートーストが表示される 🟡
