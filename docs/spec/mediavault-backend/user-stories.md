## エピック1: 作品コレクション管理（コア機能）

### ストーリー 1.1: 外部APIから作品を検索して追加する 🔵

**信頼性**: 🔵 *PRD「作品検索・追加（API）」より*

**私は** MediaVaultの単一利用者 **として**
**タイトル等で外部API（Jikan/TMDb/NDL等）を検索し、結果からコレクションに追加したい**
**そうすることで** 手入力なしに正確なメタデータを取得できる

**関連要件**: REQ-002

**詳細シナリオ**:
1. media_typeとタイトルを指定して検索APIを呼ぶ
2. システムがmedia_typeに応じた外部APIへ問い合わせる
3. 検索結果一覧からアイテムを選択し、`items`+詳細テーブルへ登録する

**前提条件**:
- 対象media_typeの外部APIキーが必要な場合は登録済みであること（REQ-015）

**優先度**: Must Have

---

### ストーリー 1.2: フォーム入力で作品を手動追加する 🔵

**信頼性**: 🔵 *PRD「作品手動追加」より*

**私は** 利用者 **として**
**外部APIに存在しない作品をフォーム入力だけで登録したい**
**そうすることで** マイナー作品や自主制作物もコレクションに含められる

**関連要件**: REQ-003

**詳細シナリオ**:
1. media_typeと各項目を入力してPOSTする
2. システムは `source=manual` で `items` を作成する（`external_id`はNULL）

**優先度**: Must Have

## エピック3: グループ・エピソード管理

### ストーリー 3.1: アニメ・ドラマのシーズン・話数を管理する 🔵

**信頼性**: 🔵 *PRD メディア別機能より*

**私は** 利用者 **として**
**シーズン単位で話数（タイトル・放送日・あらすじ）を登録・編集・一覧表示したい**
**そうすることで** シリーズ全体の視聴進捗を細かく管理できる

**関連要件**: REQ-010, REQ-101, EDGE-101

**詳細シナリオ**:
1. 親作品に対して `item_groups`（group_type=season）を作成
2. シーズンに対して `item_episodes` を複数登録
3. 話数ごとに視聴済みフラグや感想を後日紐付け（将来拡張）

**優先度**: Must Have
