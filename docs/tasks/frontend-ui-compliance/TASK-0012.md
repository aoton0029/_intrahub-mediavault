## 実装詳細

### 検索結果行の構造更新 🔵
**信頼性**: 🔵 *requirements.md REQ-008「検索結果リストをモックアップ準拠（サムネイルプレースホルダ+タイトル+等幅フォントのサブ情報）に更新する」・03_search_add.htmlの`.result-row`/`.thumb`/`.info`構造より*

既存の検索結果リストのレンダリング部分を、以下のマークアップ構造に置き換える。既存のデータ（検索結果オブジェクトの`title`/`year`/`author`等の副情報フィールド）はそのまま利用し、視覚表現のみ変更する。

```tsx
<div className="result-row" onClick={() => handleSelect(result)}>
  <div className="thumb" style={{ backgroundImage: result.thumbnailUrl ? `url(${result.thumbnailUrl})` : undefined }} />
  <div className="info">
    <div className="title">{result.title}</div>
    <div className="sub">{result.subInfo}</div>
  </div>
</div>
```

`result.subInfo`として何を表示するか（著者名・発行年・巻数など）は既存の検索API戻り値のフィールド構成に依存するため、既存実装のフィールドをそのまま`.sub`にマッピングする 🟡（フィールドの具体的な組み合わせは背景資料に明記がないため既存コードを踏襲する前提の推測）。

### サムネイルプレースホルダ 🔵
**信頼性**: 🔵 *requirements.md REQ-008「サムネイルプレースホルダ」・_shared.cssの`.thumb`定義より*

サムネイル画像が取得できない検索結果については、`.thumb`要素をグラデーション等のプレースホルダとして表示する（画像URLがない場合は`background-image`を設定しない）。

### 空状態表示 🟡
**信頼性**: 🟡 *タスク概要「結果0件時の空状態表示」より妥当な推測、EmptyStateコンポーネント（TASK-0005）の再利用を想定*

検索結果が0件の場合、TASK-0005で実装済みのEmptyStateコンポーネントを表示する。
