## 実装詳細

### タイトルバーと追加ボタン 🔵
**信頼性**: 🔵 *requirements.md REQ-005「タイトルバー右上の『＋ 作品を追加』ボタンを実装する」・01_home.htmlの`.titlebar`構造より*

`.titlebar`相当のヘッダー領域を画面上部に配置し、右端に「＋ 作品を追加」ボタンを設置する。ボタンは`.btn-accent`（アクセントカラー塗りつぶし）バリアントを使用する（TASK-0003で拡張したButtonコンポーネントを利用）。クリック時の遷移先（検索・追加画面 or 手動追加フォーム）は既存のHomePageのロジックをそのまま踏襲する 🟡（既存実装の遷移先までは背景資料に明記がないため、既存コードの遷移ロジックを変更せず視覚のみ差し替える前提）。

```tsx
<div className="titlebar">
  <h1>全体一覧</h1>
  <Button variant="accent" onClick={handleAddClick}>＋ 作品を追加</Button>
</div>
```

### フィルタバー統合 🔵
**信頼性**: 🔵 *requirements.md REQ-005「フィルタバー（`.chip`によるステータス/タグ絞り込み+検索ボックス）」・_shared.cssの`.chip`定義より*

TASK-0006で実装済みのFilterBarコンポーネントをHomePage内に配置し、既存のフィルタリングロジック（ステータス・タグでの絞り込み、検索ボックスでのテキスト検索）と接続する。フィルタの状態管理（`useState`/`useSearchParams`等）は既存実装のものを流用し、視覚部分のみ`.chip`スタイルに置き換える 🟡（既存の状態管理方式の詳細は本タスク文書のスコープ外のため、既存コードを尊重する前提）。

```tsx
<FilterBar>
  {statuses.map((s) => (
    <Chip key={s.value} active={s.active} onClick={() => toggleStatus(s.value)}>
      {s.label}
    </Chip>
  ))}
  <SearchBox value={query} onChange={setQuery} placeholder="検索..." />
</FilterBar>
```

### MediaCardグリッド確認 🔵
**信頼性**: 🔵 *architecture.md画面別スタイル適用表「HomePage.tsx→REQ-003/004/005」より*

既存のMediaCard一覧描画部分を`.card-grid`相当のCSS Grid（`repeat(auto-fill, minmax(...))`）でラップし、TASK-0008で拡張済みのMediaCard（カバー画像プレースホルダ・バッジ・お気に入り・ステータスドット）がそのまま利用されることを確認する。

### 空状態対応 🟡
**信頼性**: 🟡 *requirements.md EDGE系記載なしだが、TASK-0006 EmptyStateの汎用利用方針・要件定義「必須機能」からの妥当な推測*

フィルタ結果が0件の場合、TASK-0005のEmptyStateコンポーネント（`.empty-state`）を表示する。
