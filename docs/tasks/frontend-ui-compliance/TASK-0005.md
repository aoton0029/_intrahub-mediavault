## 実装詳細

### 更新対象と方針（新規ではなく既存更新）🔵
**信頼性**: 🔵 *タスク指示「FilterBar/EmptyStateについては『新規』ではなく『既存コンポーネントの更新』であることを明記」・実際のファイル`frontend/src/components/common/EmptyState.tsx`が既存実装として存在することより*

architecture.md「共通コンポーネント層」には`EmptyState`が新規コンポーネントとして記載されているが、これは設計時点でのディレクトリ構造記述の誤り（または設計後に先行実装された）と考えられる。実装時点では既存の`EmptyState.tsx`・`EmptyState.test.tsx`が存在するため、本タスクは既存コンポーネントへのスタイル追加更新として扱う。

### 現状実装 🔵
**信頼性**: 🔵 *既存ファイル`frontend/src/components/common/EmptyState.tsx`の内容より*

```tsx
export function EmptyState({ message, actionLabel, onAction }: EmptyStateProps) {
  return (
    <div data-testid="empty-state" className="flex flex-col items-center justify-center gap-3 py-12 text-center">
      <p className="text-sm text-muted-foreground">{message}</p>
      {actionLabel ? <Button type="button" onClick={() => onAction?.()}>{actionLabel}</Button> : null}
    </div>
  )
}
```

現状は`<p>`要素のみで見出し(`<h3>`)は存在しない。

### スタイル更新方針 🟡
**信頼性**: 🟡 *_shared.css `.empty-state`定義とタスク指示「見出しにSource Serif 4フォント」から妥当な推測。既存propsインターフェース（`message`のみ）とモックアップの「見出し+本文」構成の対応関係は資料に明記がないため推測*

`_shared.css`定義:

```css
.empty-state {
  text-align: center;
  padding: 64px 20px;
  color: var(--text-faint);
}
.empty-state h3 {
  font-family: var(--font-display);
  color: var(--text-muted);
  font-weight: 600;
  margin-bottom: 6px;
}
```

既存propsは`message`のみのため、`message`を見出し（`<h3>`相当、Source Serif 4フォント）として表示するようクラスを更新する方針とする。propsインターフェースは変更せず、既存呼び出し元（各Page）への影響を避ける。

### 既存テストへの影響確認 🔵
**信頼性**: 🔵 *タスク指示「既存の`EmptyState.test.tsx`が壊れないよう注意」より*

`data-testid="empty-state"`や`message`テキストの描画確認等、既存テストが依存しているDOM構造・テキスト内容を変更しないよう、クラス名（Tailwindユーティリティまたは`.empty-state`相当クラス）の追加・変更に限定する。
