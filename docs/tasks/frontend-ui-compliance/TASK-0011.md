## 実装詳細

### パンくずリスト 🔵
**信頼性**: 🔵 *requirements.md REQ-007「アイテム詳細画面にパンくずリストを実装する」・02_item_detail.htmlの`.breadcrumb`構造より*

画面上部に`.breadcrumb`要素を配置し、「ホーム › （カテゴリ）› アイテムタイトル」のような階層を表示する。各階層の実際のラベル・遷移先（カテゴリ名など）は既存のアイテムデータ・ルーティング構造から取得する 🟡（具体的な階層ラベルの導出ロジックは背景資料に明記がないため、既存のカテゴリ/コレクション情報を利用する前提の推測）。

```tsx
<nav className="breadcrumb">
  <Link to="/">ホーム</Link>
  <span>›</span>
  <span>{item.categoryLabel}</span>
  <span>›</span>
  <span>{item.title}</span>
</nav>
```

### タイトルバーの編集・削除ボタン 🔵
**信頼性**: 🔵 *requirements.md REQ-007「タイトルバー右の『編集』『削除』ボタン」・_shared.cssの`.btn`/`.btn-danger`定義より*

タイトルバー右側に「編集」ボタン（`.btn`）と「削除」ボタン（`.btn-danger`）を配置する。編集ボタンは既存の編集画面（`ItemFormPage.tsx`のedit mode）への遷移ロジックをそのまま利用し、削除ボタンは既存の削除確認ダイアログ（confirmDialogフック）呼び出しロジックをそのまま利用する 🟡（既存ロジックの呼び出し方法自体は既存コードに委ねる前提のため推測扱い）。

```tsx
<div className="titlebar">
  <Breadcrumb ... />
  <div className="actions">
    <Button variant="default" onClick={handleEdit}>編集</Button>
    <Button variant="danger" onClick={handleDeleteClick}>削除</Button>
  </div>
</div>
```

### ドキュメント本文（カバー・タイトル・原題・概要） 🔵
**信頼性**: 🔵 *requirements.md REQ-007「カバー画像・タイトル・原題・概要セクションを実装する」・02_item_detail.htmlの`.doc-cover`/`.doc-title`/`.doc-original`/`.doc-section`構造より*

```tsx
<article className="doc">
  <div className="doc-cover" style={{ backgroundImage: item.coverUrl ? `url(${item.coverUrl})` : undefined }} />
  <h1 className="doc-title">{item.title}</h1>
  {item.originalTitle && <p className="doc-original">{item.originalTitle}</p>}
  <section className="doc-section">
    <h2>概要</h2>
    <p>{item.summary}</p>
  </section>
</article>
```

カバー画像未設定時のプレースホルダ表示（グラデーション等）はTASK-0008のMediaCardカバー実装方針に準ずる 🟡（詳細タイトル画面固有のプレースホルダ仕様までは背景資料に明記がないため推測）。

### Propertiesパネル領域の確保（対象外の中身） 🔵
**信頼性**: 🔵 *requirements.md「Propertiesパネルの中身は…スコープ外」・REQ-006「3ペインApp Shell」より*

3カラムグリッドの右列（`--properties-w: 300px`相当）はTASK-0009のRootLayoutで確保済みであることを前提とし、本タスクでは中身（key-value等）を実装しない。右カラムには最小限のプレースホルダ（空div等）のみ配置してよい。
