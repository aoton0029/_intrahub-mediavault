## タスク概要

`frontend/src/index.css`の`:root`内に定義されている旧デザイントークン（`--bg-base`, `--bg-surface`, `--bg-elevated`, `--text-primary`, `--text-secondary`, `--border-default`等）を、`docs/frontend/ui/_shared.css`の値に**直接置換**する（`_shared.css`を別ファイルとして二重管理しない）。media_type別アクセントカラー（`--accent-anime`等8色）は変更せず維持する。Google FontsのInter / Source Serif 4 / JetBrains Monoを導入し、`--font-ui` / `--font-display` / `--font-mono`相当のCSS変数を追加する。レイアウト用トークン`--sidebar-w`, `--properties-w`, `--radius`（6px）も追加する。本タスクはPhase 1「デザイントークン基盤」の最初のタスクであり、後続タスクすべての前提となる。

## 実装詳細

### 旧トークンの直接置換 🔵
**信頼性**: 🔵 *architecture.md「デザイントークン層」（`:root`に定義された旧トークンを`_shared.css`の値に直接置換する。`_shared.css`を別ファイルとして二重管理しない）より*

現状の`frontend/src/index.css`は以下のように定義されている（実測値）。

```css
:root {
  --bg-base: #0f1115;
  --bg-surface: #1a1d23;
  --bg-elevated: #232730;
  --text-primary: #f5f5f5;
  --text-secondary: #9ca3af;
  --border-default: #2d313a;
  /* media_type別アクセントカラー（変更しない） */
  --accent-anime: #f97316;
  ...
}
```

これを`_shared.css`準拠の値に置換する。

```css
:root {
  --bg-app: #1e1e1e;
  --bg-sidebar: #161616;
  --bg-surface: #262626;
  --bg-surface-hover: #2c2c2c;
  --bg-input: #1c1c1c;
  --border: #383838;
  --border-soft: #2e2e2e;
  --text-primary: #dcddde;
  --text-muted: #8a8a8d;
  --text-faint: #5c5c5f;
  --accent: #8b6cf6;
  --accent-strong: #a48bf8;
  --accent-soft: rgba(139, 108, 246, 0.15);
  --favorite: #e0a85a;
  --status-progress: #5aa9e0;
  --status-done: #5ac98a;
  --status-none: #6b6b6e;
  --danger: #e0615a;

  /* media_type別アクセントカラー（既存維持、REQ-002） */
  --accent-anime: #f97316;
  --accent-movie: #3b82f6;
  --accent-manga: #ec4899;
  --accent-novel: #8b5cf6;
  --accent-game: #10b981;
  --accent-drama: #ef4444;
  --accent-academic-book: #14b8a6;
  --accent-paper: #64748b;
}
```

既存の`--color-bg-base`等を参照している`@theme inline`ブロックのマッピング名は、変数名変更に追随して修正が必要になるが、その調整範囲（Tailwindユーティリティ・shadcnトークンとの連携）はTASK-0002で扱うため、本タスクでは`:root`の値定義のみに留める 🔵。

### フォント導入 🔵
**信頼性**: 🔵 *_shared.cssの`@import url('https://fonts.googleapis.com/css2?family=Inter...')`より*

`_shared.css`と同じGoogle Fonts経由でInter / Source Serif 4 / JetBrains Monoを導入する。導入方法は`index.css`先頭への`@import`、または`index.html`への`<link>`追加のいずれかとする（既存実装は`@fontsource-variable/geist`をnpmパッケージ経由で導入しているため、既存方式との整合を優先し`@import url(...)`によるGoogle Fonts CDN方式を採用する）🟡 *既存の`@fontsource-variable/geist`はnpmパッケージ経由だが、`_shared.css`はCDN`@import`方式であり、資料に導入手段の指定がないため妥当な推測*。

```css
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Source+Serif+4:opsz,wght@8..60,400;8..60,600&family=JetBrains+Mono:wght@400;500&display=swap');

:root {
  --font-ui: 'Inter', -apple-system, sans-serif;
  --font-display: 'Source Serif 4', Georgia, serif;
  --font-mono: 'JetBrains Mono', monospace;
}
```

既存の`--font-heading`, `--font-sans`（`@theme inline`内、Geist Variable参照）との共存方法はTASK-0002でのTailwind連携調整時に確定する 🟡。

### レイアウト・角丸トークン追加 🔵
**信頼性**: 🔵 *_shared.cssの`--sidebar-w`, `--properties-w`, `--radius`より*

```css
:root {
  --sidebar-w: 232px;
  --properties-w: 300px;
  --radius: 6px;
}
```

既存の`--radius: 0.625rem`はshadcn/uiコンポーネント（`@theme inline`の`--radius-sm`〜`--radius-4xl`計算に使用）向けのトークンであるため、名前衝突を避けて別名（例: `--radius-shadcn: 0.625rem`）にリネームして共存させる 🟡 *資料に既存`--radius`のリネーム方針の明記はないため、衝突回避の一般的手法からの妥当な推測*。

## 単体テスト要件

デザイントークン（CSS変数）自体の値は既存のテストフレームワーク（Vitest + Testing Library）で直接アサーションすることが困難なため、本タスクでは新規の単体テストコードは作成しない方針とする 🟡 *資料に単体テスト手法の指定がないため、CSS変数特性から妥当な判断*。既存コンポーネントのテストで参照している背景色系のクラス名（Tailwindユーティリティクラス）が変更後も同一クラス名で存在し続けることを確認する。

### 確認項目: 既存コンポーネントテストの回帰確認 🟡
**信頼性**: 🟡 *既存テストへの影響有無は実装後の実行結果で確認する必要があるための方針*
- 既存の`vitest run`がすべてパスすること（クラス名変更によるコンポーネントテストの破壊がないこと）
- 後続タスク（Sidebar/MediaCard等の拡張タスク）のコンポーネントテストで、背景色・文字色を参照するクラスが変わらず適用されていることを確認する
