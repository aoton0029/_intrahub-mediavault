## タスク概要

既存の`frontend/src/components/ui/button.tsx`（shadcn/ui生成コンポーネント）に、`_shared.css`の`.btn`系クラス（`.btn`, `.btn-accent`, `.btn-ghost`, `.btn-sm`, `.btn-danger`）相当の見た目をvariant/sizeとして追加する（REQ-011）。architecture.md「共通コンポーネント層」に明記の通り、`src/components/ui/`配下の既存shadcnコンポーネントを拡張する方針であり、`.btn`系を独立コンポーネントとして二重管理しない。

## 依存タスク

- **前提タスク**: [TASK-0002](TASK-0002.md)（Tailwind CSS 4連携でトークンがユーティリティ化されていることが前提）
- **後続タスク**: [TASK-0007](TASK-0007.md)（Sidebar）, [TASK-0008](TASK-0008.md)（MediaCard）, [TASK-0009](TASK-0009.md)（RootLayout）, Phase3の全画面タスク（ボタンvariantを利用する）

## 完了条件

- [ ] `Button`コンポーネントのcva（class-variance-authority）variants定義に`accent`, `ghost`, `danger`が存在し、それぞれ`.btn-accent`, `.btn-ghost`, `.btn-danger`相当の配色になっている
- [ ] sizeバリアントに`sm`が存在し、`.btn-sm`相当（`padding: 4px 10px; font-size: 12px;`相当）になっている
- [ ] デフォルトvariant（`default`または`btn`相当）が`.btn`の基本スタイル（背景`--bg-surface`、ボーダー`--border`、文字色`--text-primary`）を再現している
- [ ] `:focus-visible`時にアクセント色（`--accent`）のフォーカスリングが表示される
- [ ] 各variantのクラス付与を検証する単体テストがすべてパスする
- [ ] 既存のButton利用箇所（他コンポーネント）が壊れていない

## 実装詳細

### 対象ファイルと方針 🔵
**信頼性**: 🔵 *architecture.md「共通コンポーネント層」：「既存の`src/components/ui/`（shadcn/ui生成コンポーネント）にvariantを追加・スタイル調整する形で`.btn`, `.btn-accent`, `.btn-ghost`, `.btn-sm`, `.btn-danger`相当の見た目を再現する」より*

- 対象: `frontend/src/components/ui/button.tsx`
- 新規コンポーネントは作成しない（REQ-011は既存Buttonの拡張で対応）

### variant/size定義の拡張 🟡
**信頼性**: 🟡 *_shared.cssの`.btn`系クラス定義から妥当な推測。cvaの具体的なvariantキー名は資料に明記がないため推測（shadcn標準の`default`/`ghost`/`destructive`命名との整合を取る想定）*

`_shared.css`の対応関係:

| `_shared.css`クラス | 想定variant/size名 | 配色 |
|---|---|---|
| `.btn`（基本） | `variant="default"` | 背景`--bg-surface`、ボーダー`--border`、文字`--text-primary`、hover時`--bg-surface-hover` |
| `.btn-accent` | `variant="accent"` | 背景`--accent`、ボーダー`--accent`、文字`#fff`、hover時`--accent-strong` |
| `.btn-ghost` | `variant="ghost"`（既存キーがあれば調整） | 背景transparent、ボーダーtransparent、文字`--text-muted`、hover時`--bg-surface-hover`+`--text-primary` |
| `.btn-danger` | `variant="danger"` | 文字`--danger`、ボーダー`--border`、背景`--bg-surface`、hover時`rgba(224,97,90,0.12)`+ボーダー`--danger` |
| `.btn-sm` | `size="sm"` | `padding: 4px 10px; font-size: 12px;` |

既存のshadcn標準variant（`destructive`, `outline`, `secondary`, `link`等）は削除せず、必要に応じて共存または統合を検討する（本タスクのスコープはREQ-011で要求される4種+基本形の再現に限定）。

### フォーカスリング 🔵
**信頼性**: 🔵 *_shared.css `:focus-visible { outline: 2px solid var(--accent); outline-offset: 1px; border-radius: 2px; }`より*

`:focus-visible`時にアクセント色のアウトラインが表示されることを確認する（アクセシビリティ、WCAG 2.1 AA、requirements.md非機能要件より）。

### 二重管理の回避 🔵
**信頼性**: 🔵 *architecture.md「アーキテクチャパターン」：「既存のshadcn/uiコンポーネント資産を壊さずスタイル拡張することで実装コストを最小化する」より*

`.btn`系のスタイルは独立したCSSクラスやコンポーネントとして再実装せず、Tailwind CSS 4の`@theme`経由でトークン化されたCSS変数をcvaのvariantスタイル内で参照する。

## 単体テスト要件

### テストケース1: variantごとのクラス付与 🔵
**信頼性**: 🔵 *完了条件・_shared.css `.btn`系クラス定義より*
- `variant="accent"`指定時にアクセント配色相当のクラス（またはスタイル）が付与されること
- `variant="ghost"`指定時にghost配色相当のクラスが付与されること
- `variant="danger"`指定時にdanger配色相当のクラスが付与されること
- variant未指定時にデフォルト（`.btn`相当）のクラスが付与されること

### テストケース2: sizeごとのクラス付与 🔵
**信頼性**: 🔵 *完了条件・_shared.css `.btn-sm`より*
- `size="sm"`指定時に`.btn-sm`相当のpadding/font-sizeスタイルが適用されること

### テストケース3: フォーカスリング 🟡
**信頼性**: 🟡 *_shared.cssのグローバル`:focus-visible`定義から妥当な推測（Buttonコンポーネント単体でのCSS適用をテストで直接検証するのは困難なため、クラス付与の確認にとどめる可能性あり）*
- フォーカス時に想定のクラス（`focus-visible:ring-*`等Tailwindユーティリティ）が付与されていること

### テストファイル 🟡
**信頼性**: 🟡 *既存テストファイルの有無は未確認のため、存在すれば追加・なければ新規作成と推測*
- `frontend/src/components/ui/button.test.tsx`（既存があれば追記、なければ新規作成）
