## タスク概要

TASK-0001〜TASK-0015を通して実施したデザイントークン置換・共通コンポーネント拡張・全5画面のスタイル適用・アクセシビリティ検証のすべての変更を対象に、最終的なリグレッションチェックとビルド確認を行う。`yarn lint`, `yarn build`（型チェック含む）, `yarn test`（Vitestによるユニットテスト全体）を実行し、視覚デザイン変更が既存の機能（API連携・状態管理・ルーティング）を壊していないことを確認する 🔵 *frontend/CLAUDE.md「開発コマンド」・requirements.md REQ-401「機能要件（画面構成・API連携・データ項目等）は変更しない。視覚表現の変更に留める」より*。

`yarn test:e2e`（Playwright）が構成されている場合は既存E2Eテストの継続パスも確認する 🔵 *frontend/CLAUDE.md「E2Eテスト（Playwright、初回は`npx playwright install`が必要）」より*。加えて、`yarn dev`起動後に全5画面（HomePage / ItemDetailPage / SearchAddPage / ItemFormPage / SettingsPage）でデザイントークンの反映状況とレイアウトがモックアップ（`docs/frontend/ui/`）と一致しているかを目視確認するチェックリストを実施する 🔵 *architecture.md「画面別スタイル適用」の対応pages一覧・requirements.md概要（モックアップ準拠）より*。

本タスクはPhase 4の最終タスクであり、本タスク完了をもってfrontend-ui-compliance要件全体（TASK-0001〜TASK-0016）の完了とする 🔵 *タスク依頼文「Phase1〜3のすべてのタスクに依存する最終フェーズ」の前提より*。本タスクはDIRECTタスク（設定・確認作業）であり、新規プロダクションコードの実装は行わない。

## 実装詳細

### 自動チェック（lint / build / test） 🔵
**信頼性**: 🔵 *frontend/CLAUDE.md「開発コマンド」記載のコマンドより*

以下のコマンドを`frontend/`ディレクトリで順に実行する。

```bash
# Lint
yarn lint

# ビルド（型チェック含む）
yarn build

# ユニットテスト（Vitest）
yarn test

# E2Eテスト（Playwright、初回は npx playwright install が必要）
yarn test:e2e
```

いずれかが失敗した場合は原因を切り分ける。
- `yarn lint`失敗: スタイル変更（クラス名・variant追加等）由来のLintルール違反（未使用importなど）を修正する
- `yarn build`失敗: TypeScriptの型エラー（新規コンポーネントのProps型不整合等）を修正する
- `yarn test`失敗: 既存コンポーネントテストがクラス名・DOM構造変更の影響を受けていないか確認し、テストの意図（機能検証）を壊さない範囲で追随修正する 🟡 *資料に失敗時の対応手順の詳細指定はないため、TASK-0001の単体テスト要件に準じた妥当な判断*
- `yarn test:e2e`失敗: 画面遷移・フォーム送信等の機能フローが視覚変更によって意図せず壊れていないか確認する 🟡 *資料にE2E失敗時の対応手順の指定はないため、REQ-401の趣旨からの妥当な推測*

### REQ-401遵守確認（機能不変の確認） 🔵
**信頼性**: 🔵 *requirements.md REQ-401「機能要件（画面構成・API連携・データ項目等）は変更しない。視覚表現の変更に留める」より*

以下の観点で、Phase1〜3の変更が機能面に影響していないことを確認する。

- API連携: `src/api/`配下のTanStack Queryフックの呼び出し箇所・パラメータが変更されていないこと（コンポーネントのスタイル調整のみで、データ取得ロジックに変更がないこと）
- 状態管理: 既存の状態管理（フォームの入力状態、フィルタ選択状態等）のロジックが変更されていないこと
- ルーティング: `react-router-dom`によるページ遷移（一覧→詳細、検索→追加フォーム等）が従来通り動作すること
