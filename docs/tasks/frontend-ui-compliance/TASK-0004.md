## 実装詳細

### コンポーネント設計 🔵
**信頼性**: 🔵 *architecture.md「共通コンポーネント層」：「`TagPill`: `.tag-pill`相当（`#`プレフィックス付きハッシュタグ風表示）」より*

```tsx
// src/components/common/TagPill.tsx
interface TagPillProps {
  label: string
}

export function TagPill({ label }: TagPillProps) {
  return (
    <span className="tag-pill" data-testid="tag-pill">
      #{label}
    </span>
  )
}
```

propsは`label: string`のみを受け取る最小構成とする（タスク概要指示より）🔵。

### スタイル仕様 🔵
**信頼性**: 🔵 *_shared.css `.tag-pill`定義より*

```css
.tag-pill {
  display: inline-flex;
  align-items: center;
  font-family: var(--font-mono);
  font-size: 11px;
  color: var(--accent-strong);
  background: var(--accent-soft);
  border-radius: 4px;
  padding: 2px 7px;
}
.tag-pill::before { content: '#'; opacity: 0.7; margin-right: 1px; }
```

`::before`による`#`表示か、JSX内でテキストとして`#`を連結するかは実装時に選択可能（🟡 資料上はCSSクラス名の対応のみで、Reactコンポーネント側の`#`実装方法までは指定がないため妥当な推測）。テストで`#`+`label`のテキストが描画されることを検証するのであれば、疑似要素よりJSX内連結の方がテスト容易性が高い。

### アクセシビリティ 🟡
**信頼性**: 🟡 *タスク指示「適切なroleまたはbutton化する場合はaria対応」より、資料に明記のない実装判断*

TagPillが単なる表示用（クリック不可）であれば`<span>`のままで問題ない。将来的にタグクリックでフィルタ絞り込み等のインタラクションを持たせる場合は`<button type="button">`化し、`aria-pressed`等の対応を検討する。本タスクの受け入れ基準はREQ-011の視覚表現のみのため、インタラクション実装はスコープ外（🔴 資料に記載なし、次回検討事項として明記のみ）。
