## 実装詳細

### 現状実装の要点 🔵
**信頼性**: 🔵 *既存ファイル`frontend/src/components/common/Sidebar.tsx`の内容より*

現状は`navItems`配列（全体一覧・一般メディア・学術書専門書・論文文献・マイリスト・タグ/カテゴリ・スタッフ・設定の8項目）を`NavLink`でフラットに描画するのみで、ブランドロゴ・件数バッジ・インデント・セクション見出し・下部固定の実装はない。

### 拡張要素1: ブランドロゴ 🔵
**信頼性**: 🔵 *dataflow.md「Sidebar拡張（REQ-003）」フロー図「ブランドロゴ表示 ドットアイコン+MediaVault」、_shared.css `.brand`定義より*

```tsx
<div className="brand">
  <span className="dot" />
  MediaVault
</div>
```

`_shared.css`: `.brand { display: flex; align-items: center; gap: 8px; padding: 4px 8px 16px; font-family: var(--font-display); font-weight: 600; font-size: 16px; }` / `.brand .dot { width: 8px; height: 8px; border-radius: 50%; background: var(--accent); }`

### 拡張要素2: ナビ項目の件数バッジ 🔵
**信頼性**: 🔵 *requirements.md REQ-003・dataflow.md「ナビ項目の件数バッジ `.nav-item .count`」より。データソースは🟡（dataflow.md備考「件数バッジの値は既存のAPI取得データ（items一覧のcount）をそのまま表示に利用する想定」より妥当な推測）*

各`navItem`にオプションの`count?: number`フィールドを追加し、既存のitems一覧取得APIレスポンスのcount値をpropsまたはコンテキスト経由でSidebarに渡す。表示ロジックのみ追加し、データ取得フロー自体は変更しない。

```tsx
{item.count !== undefined && <span className="count">{item.count}</span>}
```

具体的にどのAPIフック（TanStack Query）から件数を取得するかは資料に明記がないため（🟡）、実装時に既存の`items`一覧取得フックのレスポンス構造を確認し、Sidebar側でpropsとして受け取るか、Sidebar内で軽量なフックを呼び出すかを判断する。

### 拡張要素3: サブカテゴリのインデント階層 🔵
**信頼性**: 🔵 *dataflow.md「サブカテゴリのインデント階層 `.nav-item.indent`」、requirements.md REQ-003より*

`/collections/general`, `/collections/academic`, `/collections/paper`（メディアグループ別一覧）を「ライブラリ」セクション配下のサブ項目とみなし、`.nav-item.indent`相当のクラスを付与する。

### 拡張要素4: 「ライブラリ」セクション見出し 🔵
**信頼性**: 🔵 *requirements.md REQ-003・_shared.css `.nav-section-label`より*

```tsx
<div className="nav-section">
  <div className="nav-section-label">ライブラリ</div>
  {/* 全体一覧・一般メディア・学術書・専門書・論文・文献 のナビ項目 */}
</div>
```

セクション区分（どのnavItemを「ライブラリ」配下に含めるか）は資料に明記の一覧はないため（🟡 PRD「全体一覧」節から妥当な推測）、全体一覧＋3メディアグループを「ライブラリ」セクションとし、マイリスト・タグ/カテゴリ・スタッフは別セクション（見出しなし、または別ラベル）として扱う想定とする。

### 拡張要素5: 設定の下部固定配置 🔵
**信頼性**: 🔵 *requirements.md REQ-003・dataflow.md「設定の下部固定配置」より*

Sidebar全体を`display: flex; flex-direction: column;`（`_shared.css` `.sidebar`定義）とし、「設定」ナビ項目を含むコンテナに`margin-top: auto`を適用してSidebar下部に固定する。

```tsx
<nav className="sidebar">
  {/* ライブラリセクション、マイリスト/タグ/スタッフ等 */}
  <div style={{ marginTop: 'auto' }}>
    {/* 設定 navItem */}
  </div>
</nav>
```
