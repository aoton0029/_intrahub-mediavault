## 実装詳細

### ナビゲーション構成 🔵
**信頼性**: 🔵 *architecture.md「画面構成とルーティング」：「グローバルナビ（サイドバー）からマイリスト・タグ/カテゴリ・スタッフ・設定へアクセスする」、requirements.md REQ-004（3メディアグループ別一覧画面）より*

```tsx
// src/components/common/Sidebar.tsx（または features/navigation/Sidebar.tsx）
const navItems = [
  { to: '/', label: '全体一覧' },
  { to: '/collections/general', label: '一般メディア' },
  { to: '/collections/academic', label: '学術書・専門書' },
  { to: '/collections/paper', label: '論文・文献' },
  { to: '/mylists', label: 'マイリスト' },
  { to: '/tags-categories', label: 'タグ/カテゴリ' },
  { to: '/staff', label: 'スタッフ' },
  { to: '/settings', label: '設定' },
];
```

リンクのラベル文言（「全体一覧」「一般メディア」等）は設計文書に直接の文言指定がないため🟡妥当な推測（architecture.mdの画面名称表記を基に作成）。

### React Router v7との統合 🔵
**信頼性**: 🔵 *architecture.md「ルーティング: React Router v7」より*

`NavLink`の`className`関数（`isActive`引数）でアクティブ状態をスタイリングする。

```tsx
<NavLink to="/mylists" className={({ isActive }) => isActive ? 'nav-link active' : 'nav-link'}>
  マイリスト
</NavLink>
```

### 配置場所 🟡
**信頼性**: 🟡 *architecture.mdの「コンポーネント粒度」に「navigation」専用ディレクトリの明記はないため推測*

architecture.mdの`components/common/`（複数画面で再利用する独自コンポーネント）に該当するため`src/components/common/Sidebar.tsx`として配置する方針とするが、`features/`配下に専用ディレクトリを設ける案（🔴 設計文書に明記なし）も実装時に検討してよい。本タスクでは`components/common/`配置を基本方針とする。

### レイアウトとの統合 🔵
**信頼性**: 🔵 *TASK-0003で言及したRootLayout構成との連携*

TASK-0003で作成する`RootLayout`（または同等のレイアウトコンポーネント）内でSidebarと`<Outlet />`を組み合わせる。
