### ルート定義（13画面） 🔵
**信頼性**: 🔵 *architecture.md「画面構成とルーティング」表より*

`src/routes.tsx`にReact Router v7の`createBrowserRouter`（または`<Routes>`構成）で以下を定義する。

| パス | 画面 | pages |
|---|---|---|
| `/` | 全体一覧（ホーム） | `pages/HomePage.tsx` |
| `/collections/general` | 一覧（一般メディア） | `pages/GeneralListPage.tsx` |
| `/collections/academic` | 一覧（学術書・専門書） | `pages/AcademicListPage.tsx` |
| `/collections/paper` | 一覧（論文・文献） | `pages/PaperListPage.tsx` |
| `/items/:id` | 詳細画面 | `pages/ItemDetailPage.tsx` |
| `/search/general` | 検索・追加（一般メディア） | `pages/SearchAddPage.tsx`（group="general"） |
| `/search/academic` | 検索・追加（学術書・専門書） | `pages/SearchAddPage.tsx`（group="academic"） |
| `/search/paper` | 検索・追加（論文・文献） | `pages/SearchAddPage.tsx`（group="paper"） |
| `/items/new/general` | 手動追加（一般メディア） | `pages/ItemFormPage.tsx`（mode="create", group="general"） |
| `/items/new/academic` | 手動追加（学術書・専門書） | `pages/ItemFormPage.tsx`（mode="create", group="academic"） |
| `/items/new/paper` | 手動追加（論文・文献） | `pages/ItemFormPage.tsx`（mode="create", group="paper"） |
| `/items/:id/edit` | 編集 | `pages/ItemFormPage.tsx`（mode="edit"） |
| `/mylists` | マイリスト | `pages/MyListsPage.tsx` |
| `/tags-categories` | タグ/カテゴリ管理 | `pages/TagsCategoriesPage.tsx` |
| `/staff` | スタッフ管理 | `pages/StaffPage.tsx` |
| `/settings` | 設定 | `pages/SettingsPage.tsx` |

注: architecture.mdは「合計13画面構成」と記載するが、pages単位（コンポーネント単位）では`SearchAddPage`/`ItemFormPage`がgroup別に再利用されるため、上表のURLパスは16パスとなる（🟡 architecture.mdの13画面はpagesコンポーネント数を指し、パス数とは一致しない点に注意。`HomePage`/`GeneralListPage`/`AcademicListPage`/`PaperListPage`/`ItemDetailPage`/`SearchAddPage`/`ItemFormPage`/`MyListsPage`/`TagsCategoriesPage`/`StaffPage`/`SettingsPage`の11種類+α、architecture.md本文の「13画面」表現とpages実体数の対応は再確認が必要）。

本タスクでは各pageに対応するプレースホルダコンポーネント（`export default function HomePage() { return <div>HomePage</div>; }`等）を作成しルーティング疎通を確認する。実装本体は各pageの実装タスク（Phase 2以降）で行う。

### App.tsx設定 🔵
**信頼性**: 🔵 *architecture.md「フロントエンド全体構成」（TanStack Query 5）、note.md（sonner採用）より*

```tsx
// src/App.tsx
import { RouterProvider } from 'react-router-dom';
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { Toaster } from 'sonner';
import { router } from './routes';

const queryClient = new QueryClient();

export default function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <RouterProvider router={router} />
      <Toaster richColors position="top-right" />
    </QueryClientProvider>
  );
}
```

`Toaster`の`position`/`richColors`等のpropsは設計文書に明記がないため🟡妥当な推測。
