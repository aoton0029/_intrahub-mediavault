## タスク概要
`pages/HomePage.tsx`を実装する。コレクション全体をカード/リスト表示し（REQ-001）、TASK-0010のFilterBarを統合してURL同期付きの絞り込み（REQ-002/003）を行う。アイテムが0件の場合はEmptyStateコンポーネントを表示し追加画面への導線を出す（EDGE-101）。後続のメディアグループ別一覧画面（TASK-0012〜0014）が共有する一覧表示ロジック・コンポーネントの基盤となる。

- **後続タスク**: TASK-0017（詳細画面遷移、Phase3想定）

## 実装詳細

### 1. 画面レイアウトとデータ取得 🔵
**信頼性**: 🔵 *dataflow.md 機能1（全体一覧の閲覧・絞り込み）シーケンス図より*

`useSearchParamsFilter`でURLクエリパラメータからフィルタ条件を読み出し、`useItemsQuery(filters)`を実行する。取得した`items`を`MediaCard`のグリッドでレンダリングする。レスポンスの`pagination`情報を用いてページ送りUIを表示する。

**実装ファイル**: `frontend/src/pages/HomePage.tsx`

### 2. FilterBar統合 🔵
**信頼性**: 🔵 *TASK-0010の設計（controlledコンポーネント）より*

`useSearchParamsFilter`が返す`filters`と`setFilters`をFilterBarにpropsで渡す。タグ・カテゴリ選択肢は別途`useTagsQuery`/`useCategoriesQuery`（既存または別タスクの汎用フック）で取得し渡す。未取得時はFilterBarのセレクトを`disabled`にする。

**実装ファイル**: `frontend/src/pages/HomePage.tsx`

### 3. EmptyState表示 🟡
**信頼性**: 🟡 *EDGE-101「一般的なUIパターンから妥当な推測」を継承*

`items.length === 0`かつローディング完了時に`EmptyState`（TASK-0006で実装済みの共通コンポーネント想定）を表示し、「+ 追加する」ボタンから検索・追加画面（`/search/general`等）または手動追加画面へのリンクを表示する。

**実装ファイル**: `frontend/src/pages/HomePage.tsx`

## 単体テスト要件

### テストケース1: アイテム一覧がカード表示される 🔵
**Given** `useItemsQuery`が3件のItemを返す
**When** HomePageをレンダリングする
**Then** 3件分のMediaCardが表示される

### テストケース2: 0件時にEmptyStateが表示される 🟡
**Given** `useItemsQuery`が0件を返す
**When** HomePageをレンダリングする
**Then** EmptyStateと追加画面への導線リンクが表示される

### テストケース3: FilterBar操作で一覧が再取得される 🔵
**Given** HomePageがレンダリングされている
**When** FilterBarで`mediaType=anime`を選択する
**Then** URLクエリパラメータに`media_type=anime`が反映され、`useItemsQuery`が新しいfiltersで再実行される

### テストケース4: ページ送り操作でpageクエリパラメータが更新される 🟡
**Given** `pagination={page:1, limit:20, total:50}`
**When** 「次のページ」ボタンを押下する
**Then** URLの`page`が2になり一覧が再取得される 🟡 *ページングUIの具体的な操作方式は要件に明記なく妥当な推測*

### テストケース5: カードクリックで詳細画面へ遷移する 🔵
**Given** 1件以上のMediaCardが表示されている
**When** カードをクリックする
**Then** `/items/:id`へのナビゲーションが発生する

## UI/UX要件
- **ローディング状態**: 初回読み込み中はMediaCardのスケルトン（shimmer等）をグリッド表示する 🟡 *NFR-002から一般的なローディングUIパターンを推測*
- **エラー表示**: `useItemsQuery`がエラーの場合、画面上部にエラーメッセージとリトライボタンを表示する
- **モバイル対応**: カードグリッドをTailwindのレスポンシブグリッド（`grid-cols-2 md:grid-cols-4 lg:grid-cols-6`等）で実装し、モバイルでは列数を減らす
- **アクセシビリティ**: カードはキーボード操作（Tab+Enter）で詳細画面へ遷移可能にし、ページ送りボタンには`aria-label`を付与する（NFR-202）
