## 実装詳細

### ダークテーマCSS変数定義 🟡
**信頼性**: 🟡 *note.md「既存デザインシステム」に`--bg-base`, `--accent`等の変数名が存在することは🔵記載されているが、元ファイル`docs/frontend/ui/01_components.html`・`docs/frontend/docs/ui/_shared.css`は本リポジトリのgit statusで削除済み（`D`表示）であり、具体的なカラー値は確認できないため値自体は🟡推測*

`src/index.css`に以下方針でCSS変数を定義する（変数名はnote.mdの記載に準拠、具体的な16進値は一般的なダークテーマ配色から妥当な値を仮定し、実装時に元デザインファイルが復元可能であれば値を差し替える）。

```css
:root {
  --bg-base: #0f1115;
  --bg-surface: #1a1d23;
  --bg-elevated: #232730;
  --text-primary: #f5f5f5;
  --text-secondary: #9ca3af;
  --border-default: #2d313a;
  --accent: #6366f1;
}
```

🔴 上記の具体的な16進値はnote.mdに明記されていないため赤信号。元デザインファイル（削除済み）の復元、またはユーザーへの確認を推奨する。

### media_type別アクセントカラー 🟡
**信頼性**: 🟡 *note.md「既存デザインシステム」に「media_type別アクセントカラー: anime/movie/manga/novel/game/drama/book/paper」と記載あり（🔵 種別存在）だが、academic_bookとbookの対応関係・具体的な色自体は推測（🟡🔴）*

note.mdの記載は`book/paper`だが、interfaces.tsの`MediaType`は`academic_book`/`paper`であるため、`book`は`academic_book`に対応すると解釈する（🟡 妥当な推測）。

```css
:root {
  --accent-anime: #f97316;
  --accent-movie: #3b82f6;
  --accent-manga: #ec4899;
  --accent-novel: #8b5cf6;
  --accent-game: #10b981;
  --accent-drama: #ef4444;
  --accent-academic-book: #14b8a6;
  --accent-paper: #64748b;
}
```

🔴 具体的な色相の割り当てはnote.mdに数値記載がないため赤信号。デザイン上の最終決定はTASK-0006のMediaTypeBadge実装時に再確認することを推奨する。

### Tailwind v4 @theme連携 🔵
**信頼性**: 🔵 *architecture.md「UIライブラリ」Tailwind CSS 4 + shadcn/uiより*

Tailwind v4の`@theme inline`構文で上記CSS変数をユーティリティクラス（例: `bg-base`, `text-accent-anime`）として利用可能にする。

```css
@theme inline {
  --color-bg-base: var(--bg-base);
  --color-accent-anime: var(--accent-anime);
  /* 以下、各トークンを同様に対応付け */
}
```

### MediaType→アクセントカラーのマッピングユーティリティ 🟡
**信頼性**: 🟡 *interfaces.ts MediaType型・本タスクのCSS変数定義から妥当な実装*

`src/lib/`に`getMediaTypeAccentClass(mediaType: MediaType): string`のようなマッピング関数を用意し、MediaCard・MediaTypeBadge（TASK-0006）から参照できるようにする。
