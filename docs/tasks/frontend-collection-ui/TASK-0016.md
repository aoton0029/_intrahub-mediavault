## タスク概要
`pages/SearchAddPage.tsx`を実装する。`group`プロパティ（`general`/`academic`/`paper`）で挙動を分岐し（REQ-404）、ルート`/search/general`・`/search/academic`・`/search/paper`に対応する。検索語入力→検索実行（TASK-0015の`useExternalSearchQuery`）→結果一覧表示→1件選択→インポート（`useImportItemMutation`）→詳細画面遷移、というREQ-005のフローを実装する。`API_KEY_NOT_CONFIGURED`時は手動追加画面への導線を表示し（REQ-203）、`EXTERNAL_API_TIMEOUT`時は再試行ボタンを表示する（EDGE-001）。

## 実装詳細

### 1. 画面構造とgroup分岐 🔵
**信頼性**: 🔵 *architecture.md「pages/SearchAddPage.tsx（group propで分岐）」より*

`group: 'general' | 'academic' | 'paper'`をpropsまたはルートパラメータから受け取り、`group`に応じた`media_type`セレクトの選択肢を決定する。検索フォーム（検索語入力欄＋media_typeセレクト＋検索ボタン）をreact-hook-formで実装する。

**実装ファイル**: `frontend/src/pages/SearchAddPage.tsx`, `frontend/src/routes.tsx`

### 2. 検索実行と結果表示 🔵
**信頼性**: 🔵 *dataflow.md 機能2 シーケンス図「検索語を入力し検索実行→GET /items/search→結果カード一覧表示」より*

検索ボタン押下時に`ExternalSearchQuery`を構築し`useExternalSearchQuery`を実行する。`isLoading`中はローディング表示、成功時は`ExternalSearchResultItem[]`をカード一覧（タイトル・カバー画像・公開日）として表示する。

**実装ファイル**: `frontend/src/pages/SearchAddPage.tsx`

### 3. インポート実行と画面遷移 🔵
**信頼性**: 🔵 *dataflow.md 機能2「1件選択し『追加』→POST /items/import→成功→toast表示+詳細画面へ遷移」より*

検索結果カードの「追加」ボタン押下で`useImportItemMutation().mutate({mediaType, externalId, raw})`を実行する。成功時はsonner toastで「追加しました」を表示し、`useNavigate()`で`/items/:id`へ遷移する。

**実装ファイル**: `frontend/src/pages/SearchAddPage.tsx`

### 4. エラー種別ごとのUI分岐 🔵
**信頼性**: 🔵 *REQ-203・EDGE-001・dataflow.mdエラーハンドリングフローより*

検索エラー時、`error instanceof ApiClientError`かつ`error.code`で分岐する。
- `API_KEY_NOT_CONFIGURED`: 「APIキーが設定されていません」メッセージ＋「手動で追加する」ボタン（`/items/new/:group`へリンク）を表示
- `EXTERNAL_API_TIMEOUT`: 「検索がタイムアウトしました」メッセージ＋「再試行」ボタン（検索を再実行）を表示
- その他: 汎用エラートーストを表示

**実装ファイル**: `frontend/src/pages/SearchAddPage.tsx`

## UI/UX要件
- **ローディング状態**: 検索実行中・インポート実行中はボタンを`disabled`にしローディングインジケータ（スピナー）を表示する
- **エラー表示**: 2種類のエラー導線（API_KEY_NOT_CONFIGURED→手動追加導線、EXTERNAL_API_TIMEOUT→再試行ボタン）をエラーメッセージ領域に明確に分けて表示する。その他エラーは汎用トーストで表示する
- **モバイル対応**: 検索結果カード一覧はHomePage同様レスポンシブグリッドとし、モバイルでは1〜2列表示にする
- **アクセシビリティ**: 検索語入力欄に`label`を関連付け、検索ボタンはEnterキーでも実行可能にする。エラーメッセージ領域は`role="alert"`を付与し読み上げ対応する（NFR-202）
