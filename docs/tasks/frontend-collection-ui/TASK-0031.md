## タスク概要

`src/api/import.ts`にブクログCSV・Steamライブラリの一括インポート用TanStack Queryフック（`useImportBooklogMutation`, `useImportSteamMutation`）を実装する。`useImportBooklogMutation`は`POST /import/booklog`へmultipart/form-dataでCSVファイルを送信し、`useImportSteamMutation`は`POST /import/steam`へSteam IDを送信する。`SettingsPage`のインポートタブにCSVファイル選択UI・Steam ID入力UI・実行ボタンを実装し、実行後は`ImportSummary`（`successCount`/`failureCount`/`failures[]`）を画面に表示する（REQ-022, EDGE-002）。

## 依存タスク

- **前提タスク**: TASK-0030（設定ページのタブ構成・APIキー管理）
- **後続タスク**: なし

## 完了条件

- [ ] `useImportBooklogMutation()`が`POST /import/booklog`にCSVファイルをmultipart/form-dataで送信する
- [ ] `useImportSteamMutation()`が`POST /import/steam`にSteam IDを送信する
- [ ] インポートタブにCSVファイル選択UI（ファイル選択ダイアログ）が実装されている

- [ ] 成功時はアイテム一覧クエリ（`['items']`）が無効化される

## 実装詳細

### 1. fetch関数・ミューテーション実装 🔵
**信頼性**: 🔵 *architecture.md「リソース別フック」・interfaces.ts ImportSummary/ImportFailureより*

`importBooklog(file: File): Promise<ImportSummary>`はFormDataを構築し`apiClient`経由でmultipart/form-dataとして`POST /import/booklog`へ送信する。`importSteam(steamId: string): Promise<ImportSummary>`は`POST /import/steam`にJSONボディで送信する。いずれもTASK-0005の`apiClient`を用いる。

**実装ファイル**: `frontend/src/api/import.ts`

### 2. キャッシュ無効化 🔵
**信頼性**: 🔵 *dataflow.md「データ整合性の保証」キャッシュ無効化方針より*

両ミューテーションの`onSuccess`で`queryClient.invalidateQueries({queryKey: ['items']})`を呼び出し、インポートで追加されたアイテムが一覧に反映されるようにする。

**実装ファイル**: `frontend/src/api/import.ts`

### 3. SettingsPageインポートタブの実装 🔵
**信頼性**: 🔵 *REQ-022・dataflow.md 機能5（一括インポート）より*

TASK-0030で実装したタブ構成にインポートタブの内容を追加する。CSVファイル選択（`<input type="file" accept=".csv">`）とSteam ID入力フィールドをそれぞれ独立したセクションとして配置し、各セクションに専用の実行ボタンを設置する。実行ボタン押下時に対応するミューテーションの`mutate`を呼び出す。

**実装ファイル**: `frontend/src/pages/SettingsPage.tsx`（または`features/settings/ImportTab.tsx`）

### 4. 進捗表示とImportSummary結果表示の実装 🟡
**信頼性**: 🟡 *NFR-203・EDGE-002から妥当な推測*

ミューテーションの`isPending`状態を用いて実行中はスピナー/プログレスバー等を表示する。完了後は`data`（`ImportSummary`）から`successCount`・`failureCount`をサマリーカードで表示し、`failureCount > 0`の場合は`failures[]`を`rowNumber`・`reason`を含むテーブルまたはリストで表示する。

**実装ファイル**: `frontend/src/pages/SettingsPage.tsx`（または`features/settings/ImportTab.tsx`）

## 単体テスト要件

### テストケース1: useImportBooklogMutationがmultipart/form-dataでCSVファイルを送信する 🔵
**Given** CSVファイル（`File`オブジェクト）
**When** `mutate(file)`を実行する
**Then** `POST /import/booklog`へ`multipart/form-data`形式でファイルが送信される

### テストケース2: useImportSteamMutationがSteam IDを送信する 🔵
**Given** 有効なSteam ID文字列
**When** `mutate(steamId)`を実行する
**Then** `POST /import/steam`へ`{steamId}`相当のボディが送信される

### テストケース3: インポート成功時にアイテム一覧クエリが無効化される 🔵
**Given** インポート実行
**When** ミューテーションが成功する
**Then** `queryClient.invalidateQueries`が`queryKey:['items']`で呼ばれる

### テストケース4: インポート完了後に成功件数・失敗件数が表示される 🔵
**Given** `ImportSummary{successCount: 8, failureCount: 2, failures: [...]}`が返る
**When** インポートタブで結果を確認する
**Then** 画面上に「成功: 8件」「失敗: 2件」相当の表示がされる

### テストケース5: 失敗件数1件以上の場合に失敗理由一覧が表示される 🔵
**Given** `failures: [{rowNumber: 3, reason: 'invalid date'}, {rowNumber: 7, reason: 'missing title'}]`
**When** インポート結果を表示する
**Then** 各失敗行の`rowNumber`と`reason`が一覧表示される（EDGE-002）

### テストケース6: インポート実行中に進捗表示がされる 🟡
**Given** インポートミューテーションが`isPending=true`の状態
**When** インポートタブを表示する
**Then** 進捗インジケータ（スピナー等）が表示される 🟡 *NFR-203から類推、具体UIは推測*

### テストケース7: ファイル未選択でCSVインポート実行ボタンを押せない 🟡
**Given** CSVファイルが未選択
**When** 実行ボタンの状態を確認する
**Then** 実行ボタンが無効化されている 🟡 *一般的なフォームUXパターンから推測、要件に明記なし*
