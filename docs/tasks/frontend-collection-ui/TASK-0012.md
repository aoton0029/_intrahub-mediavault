## タスク概要
`pages/GeneralListPage.tsx`を実装する。一般メディア（anime/movie/drama/manga/novel/game）専用の一覧画面を提供し（REQ-004）、ルート`/collections/general`に対応する。HomePage（TASK-0011）で構築した一覧表示ロジック・コンポーネント（カードグリッド・FilterBar・EmptyState・ページング）を共有し、本画面固有の差分（`media_type`の選択肢を一般メディア6種に固定）のみを追加する。

## 依存タスク
- **前提タスク**: TASK-0011（HomePage、共有ロジックの抽出元）
- **後続タスク**: なし

## 完了条件
- [ ] `/collections/general`ルートでアクセス可能
- [ ] `media_type`フィルタの選択肢が`anime`/`movie`/`drama`/`manga`/`novel`/`game`の6種に固定され、これら以外（`academic_book`/`paper`）は表示されない
- [ ] FilterBar・カードグリッド・EmptyState・ページングはHomePageと同等の挙動を持つ（共有ロジック経由）
- [ ] 画面初期表示時に上記6種いずれかの`media_type`が指定されていない場合は、6種全件を対象とする（OR条件、もしくはAPI側が複数media_type対応していない場合はクライアント側で6種をまとめて扱う設計とする）

## 実装詳細

### 1. 共有一覧ロジックの再利用 🔵
**信頼性**: 🔵 *architecture.md「HomePageと共通ロジックをフック/コンポーネント共有」（タスク概要記載）より*

TASK-0011で抽出した共有コンポーネント/フック（例: `ItemListView`または`useItemListPage`）を呼び出し、`mediaTypeOptions={['anime','movie','drama','manga','novel','game']}`をFilterBarへ渡す。

**実装ファイル**: `frontend/src/pages/GeneralListPage.tsx`

### 2. ルーティング設定 🔵
**信頼性**: 🔵 *architecture.md 画面構成とルーティング表より*

`src/routes.tsx`に`/collections/general` → `GeneralListPage`のルートを追加する（ルート定義自体がTASK-0007等で既に骨格がある場合は追記のみ）。

**実装ファイル**: `frontend/src/routes.tsx`, `frontend/src/pages/GeneralListPage.tsx`

### 3. 一般メディア6種の固定フィルタ適用 🟡
**信頼性**: 🟡 *バックエンドAPIが単一media_type値のみ受け付ける場合、6種いずれにも合致する一覧をどう取得するかはAPI仕様の制約に依存し、要件には明記なし*

バックエンドAPI（`GET /items`）の`media_type`パラメータが単一値のみを受け付ける場合、本画面ではmedia_typeパラメータ自体を送らずクライアント側で6種に該当するアイテムのみフィルタするか、ユーザーが個別に1種を選択した場合のみmedia_typeパラメータを送信する設計とする。実装時にバックエンドAPI仕様（api-endpoints.md）を確認すること。

**実装ファイル**: `frontend/src/pages/GeneralListPage.tsx`

## 単体テスト要件

### テストケース1: media_typeフィルタの選択肢が6種に固定される 🔵
**Given** GeneralListPageをレンダリングする
**When** FilterBarのmedia_typeセレクトを開く
**Then** `anime`/`movie`/`drama`/`manga`/`novel`/`game`の6種のみが選択肢に表示される

### テストケース2: academic_book/paperは選択肢に含まれない 🔵
**Given** GeneralListPageをレンダリングする
**When** FilterBarのmedia_typeセレクトを確認する
**Then** `academic_book`と`paper`は選択肢に含まれない

### テストケース3: 個別media_type選択でフィルタが反映される 🔵
**Given** GeneralListPageが表示されている
**When** `manga`を選択する
**Then** URLクエリパラメータに`media_type=manga`が反映され一覧が再取得される
