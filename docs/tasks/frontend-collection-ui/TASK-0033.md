## タスク概要

Phase2〜5で個別に実装された全13画面（全体一覧/グループ別一覧3種/詳細/検索追加3種/手動追加3種/編集/マイリスト/タグ・カテゴリ管理/スタッフ管理/設定）について、`src/routes.tsx`のルート定義が`architecture.md`「画面構成とルーティング」表と一致しているか、および画面遷移が全体一覧画面またはメディアグループ別一覧画面を起点として詳細・検索追加・手動追加へ正しく遷移する構成になっているかを最終確認・調整する（REQ-404）。検索追加・手動追加・グループ別一覧がメディアグループ（一般メディア/学術書・専門書/論文・文献）ごとに別画面として正しくルーティングされているかを確認し、不整合があれば修正する。加えて、存在しないパスへのアクセス時の404ページ表示、存在しない`item id`での詳細・編集画面アクセス時のリダイレクト・エラー表示を実装・確認する。

## 実装詳細

### 1. ルート定義の整合性確認・調整 🔵
**信頼性**: 🔵 *architecture.md「画面構成とルーティング」表（合計13画面）より*

`src/routes.tsx`に定義された全13ルートが設計表のパス・対応pagesと一致しているかを確認する。`SearchAddPage.tsx`・`ItemFormPage.tsx`がそれぞれ`group`/`mode`propを正しく受け取る形でルートごとに個別指定されているか（例: `<Route path="/search/general" element={<SearchAddPage group="general" />} />`）を確認し、不整合があれば修正する。

**実装ファイル**: `frontend/src/routes.tsx`

### 2. 起点画面からの遷移導線確認 🔵
**信頼性**: 🔵 *REQ-404「全体一覧画面またはメディアグループ別一覧画面を起点として詳細・検索追加・手動追加へ遷移」より*

`HomePage.tsx`, `GeneralListPage.tsx`, `AcademicListPage.tsx`, `PaperListPage.tsx`の各カード/リストから`/items/:id`への遷移リンク、および各画面のヘッダー/アクションボタンから対応する`/search/{group}`・`/items/new/{group}`への遷移リンクが正しいメディアグループのパスを指しているかを確認する。`HomePage`（全体一覧）はメディアグループ非依存のため、検索追加・手動追加への導線は一般メディアグループへのデフォルト遷移、またはグループ選択UIを経由する設計のいずれかで統一する。

**実装ファイル**: `frontend/src/pages/HomePage.tsx`, `frontend/src/pages/GeneralListPage.tsx`, `frontend/src/pages/AcademicListPage.tsx`, `frontend/src/pages/PaperListPage.tsx`

### 3. 404ページの実装 🟡
**信頼性**: 🟡 *一般的なReact Router構成から妥当な推測（設計文書に404ページの個別記載なし）*

`routes.tsx`のルート定義末尾に`path="*"`のキャッチオールルートを追加し、`pages/NotFoundPage.tsx`（新規）を表示する。NotFoundPageには全体一覧（`/`）への戻りリンクを設置する。

**実装ファイル**: `frontend/src/routes.tsx`, `frontend/src/pages/NotFoundPage.tsx`

### 4. 存在しないitem idへのアクセス時の処理確認 🔵
**信頼性**: 🔵 *dataflow.mdエラーハンドリングフロー「`*_NOT_FOUND 404` → 一覧へリダイレクト+エラートースト」より*

`ItemDetailPage.tsx`・`ItemFormPage.tsx`（編集モード）にて、`useItemQuery`が`ITEM_NOT_FOUND`（404）エラーを受け取った場合に、sonner toastでエラーメッセージを表示しつつ`/`（全体一覧）へリダイレクトする処理が実装されているかを確認する。未実装の場合は実装する。

**実装ファイル**: `frontend/src/pages/ItemDetailPage.tsx`, `frontend/src/pages/ItemFormPage.tsx`
