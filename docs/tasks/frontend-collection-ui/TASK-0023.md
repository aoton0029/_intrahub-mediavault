## 実装内容

### 1. media_type別フォーム部品 🔵

**信頼性**: 🔵 *interfaces.ts AnimeDetails/MovieDetails/DramaDetails/MangaDetails/NovelDetails/GameDetails（54-102行目）・REQ-004（一般メディアグループ）より*

`src/features/item-form/components/` に以下6種のメディア別詳細フォーム部品を実装する。各部品は対応する`*Details`型のzodスキーマ（TASK-0022の`details`部分を`.extend()`して構成）に基づき、react-hook-formの`useFormContext`を用いて入力UIを提供する。

- `AnimeDetailsFields.tsx`（`AnimeDetails`: episodeCount, seasonCount, studio, genreList, sourceType, jikanId）
  - jikanIdは`source==='api'`時のみ表示専用（REQ-201と同様の方針を`details`内項目にも適用 🟡 ItemBase.externalIdと同様の妥当な推測）
- `MovieDetailsFields.tsx`（`MovieDetails`: runtimeMinutes, director, genreList, tmdbId）
- `DramaDetailsFields.tsx`（`DramaDetails`: episodeCount, seasonCount, network, genreList, tmdbId）
- `MangaDetailsFields.tsx`（`MangaDetails`: volumeCount, chapterCount, author, illustrator, magazine, jikanId）
- `NovelDetailsFields.tsx`（`NovelDetails`: volumeCount, author, publisher, isbn, openlibraryId, googleBooksId）
- `GameDetailsFields.tsx`（`GameDetails`: platformList, developer, publisher, steamAppid, igdbId）

各フォームの`genreList`/`platformList`は文字列配列入力（タグ追加形式のUIコンポーネント、例: Enterキーで追加、Badgeで表示・削除可 🟡 一般的なタグ入力UIパターンから推測、要件に明記なし）として実装する。

各フォーム部品はTASK-0026（ItemFormPage統合実装）から`media_type`に応じて動的に差し替えられることを前提に、共通インターフェース（`Control`/`register`をpropsで受け取る、もしくは`useFormContext`でフォームコンテキストを共有する設計）を持たせる。

## 単体テスト要件 🔵

**信頼性**: 🔵 *REQ-004・NFR-201より*

- 各メディア別フォーム部品（6種）について
  - 対応する全フィールドが表示されること
  - 数値項目（episodeCount, seasonCount, runtimeMinutes, volumeCount, chapterCount）に文字列等の不正値を入力した場合にバリデーションエラーとなること
  - 文字列配列項目（genreList, platformList）の追加・削除が正しく動作すること
  - `jikanId`/`tmdbId`/`igdbId`/`steamAppid`等のexternal_id系項目について、`source==='api'`の場合は編集不可（表示専用）として描画されること（REQ-201相当）
  - 任意項目を空のまま送信してもバリデーションエラーにならないこと
