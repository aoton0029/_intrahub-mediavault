## タスク概要

`SettingsPage`のエクスポートタブに、Obsidian/Notion向けエクスポート機能のUIエントリ（ボタン）を表示する。ただし本要件はバックエンド側が次フェーズ対象外であることが確認されており、フロントエンドも同スコープとするため、ボタンは無効化（`disabled`）または「未対応」のラベル・バッジを表示するのみとし、実際のエクスポート処理は実装しない（REQ-023）。

## 依存タスク

- **前提タスク**: TASK-0030（設定ページのタブ構成）
- **後続タスク**: なし

## 完了条件

- [ ] `SettingsPage`にエクスポートタブが存在し、Obsidian向けエクスポートボタンが表示される
- [ ] `SettingsPage`にエクスポートタブが存在し、Notion向けエクスポートボタンが表示される
- [ ] 両ボタンは無効化（`disabled`）されている、または押下しても処理が実行されず「未対応」である旨が表示される
- [ ] ボタン近傍に「現在未対応」等、スコープ対象外であることを示す説明文が表示される
- [ ] ボタン押下によるAPIリクエストが一切発生しない

---

## 実装詳細

### エクスポートタブのUIエントリ実装 🟡
**信頼性**: 🟡 *REQ-023「未実装としてもよい（無効化または『未対応』表示）」より*

TASK-0030で実装したタブ構成にエクスポートタブの内容を追加する。「Obsidianへエクスポート」「Notionへエクスポート」の2ボタンをshadcn/uiの`Button`（`disabled`属性付き）で配置し、各ボタン下部に「この機能は現在のバージョンでは未対応です」等の説明テキストを表示する。クリックハンドラは実装しない、またはno-opとする。

**実装ファイル**: `frontend/src/pages/SettingsPage.tsx`（または`features/settings/ExportTab.tsx`）

## 注意事項

- 将来的にエクスポート機能を実装する際は、本タスクで配置したボタンの`disabled`属性とno-opハンドラを差し替える形で拡張できるよう、ボタンのpropsやイベントハンドラの差し替えが容易な構造にしておくこと。
- バックエンドAPIエンドポイント（エクスポート用）は本要件のスコープには存在しないため、フロントエンドから何らかのエンドポイントを推測で呼び出してはならない。
