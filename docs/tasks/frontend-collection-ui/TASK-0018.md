## 背景・目的

アニメ・ドラマはシーズン単位（`group_type=season`）で話数（episode）を管理し、漫画・小説は巻単位（`group_type=volume`）でグループのみを管理する（話数登録UIは表示しない）。映画は任意で章単位（`group_type=chapter`）グループ表示を提供できる。本タスクではこのメディア別分岐ロジックを持つ`GroupSection`コンポーネントと、グループ・話数のCRUDを行うAPIフックを実装する。

## 実装詳細

### 対象ファイル

- `src/api/groups.ts`（新規）: グループ・話数CRUDフック
- `src/features/groups/GroupSection.tsx`（新規）: メディア別表示分岐の親コンポーネント
- `src/features/groups/SeasonGroupList.tsx`（新規）: season用、話数登録UI付き
- `src/features/groups/VolumeGroupList.tsx`（新規）: volume用、話数登録UIなし
- `src/features/groups/ChapterGroupList.tsx`（新規、オプション）: movie用章グループ表示
- `src/features/groups/EpisodeList.tsx`（新規）: 話数一覧・登録・編集

### API要件

- 🔵 **REQ-015**: `POST /items/:id/groups`, `GET /items/:id/groups`によるグループCRUDフック実装。
  *出典: requirements.md REQ-015*
- 🔵 **REQ-016**: `POST /groups/:group_id/episodes`, `GET /groups/:group_id/episodes`による話数CRUDフック実装。
  *出典: requirements.md REQ-016*
- 🔵 `src/api/groups.ts`に`useItemGroupsQuery(itemId)`, `useCreateGroupMutation(itemId)`, `useGroupEpisodesQuery(groupId)`, `useCreateEpisodeMutation(groupId)`等を定義する。
  *出典: architecture.md「リソース別フック」方針、interfaces.ts CreateGroupRequest/CreateEpisodeRequest*

### 機能要件対応（メディア別分岐）

- 🔵 **REQ-101**: `mediaType`が`anime`または`drama`の場合、`GroupSection`は`SeasonGroupList`を表示し、season配下に話数登録・編集・一覧UI（`EpisodeList`）を表示する。
  *出典: requirements.md REQ-101, REQ-015*
- 🔵 **REQ-102**: `mediaType`が`manga`または`novel`の場合、`GroupSection`は`VolumeGroupList`を表示する。話数（エピソード）入力UIは表示してはならない。
  *出典: requirements.md REQ-102, REQ-016*
- 🔵 **EDGE-004**: `group_type=volume`のグループには話数登録ボタンを表示しない設計とする。これによりバックエンドの`INVALID_GROUP_TYPE_FOR_EPISODES`エラーを未然に回避する（UI側で発生させない設計であり、エラーハンドリングではなくUI制御で対応する）。
  *出典: requirements.md EDGE-004, dataflow.md 機能4のフロー図*
- 🟡 **REQ-017/REQ-301**: `mediaType`が`movie`の場合、`GroupSection`は`ChapterGroupList`（章単位グループ表示）を任意で提供してもよい。本タスクでは表示のみ実装し、章グループの作成UIまでは必須としない（オプション要件のため最小実装で可）。
  *出典: requirements.md REQ-017, REQ-301（オプション要件）*

### コンポーネント分岐ロジック

```tsx
// GroupSection.tsx 概念コード
switch (item.mediaType) {
  case 'anime':
  case 'drama':
    return <SeasonGroupList itemId={item.id} />;
  case 'manga':
  case 'novel':
    return <VolumeGroupList itemId={item.id} />;
  case 'movie':
    return <ChapterGroupList itemId={item.id} />; // オプション
  default:
    return null; // game/academic_book/paperはグループ管理対象外
}
```

🟡 *interfaces.ts GroupType（season/volume/chapter）とMediaTypeの対応関係から妥当な推測。game/academic_book/paperはrequirements.mdにグループ管理要件の記載がないため対象外と判断。*
