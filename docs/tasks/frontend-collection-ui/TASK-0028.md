## タスク概要

`src/api/mylists.ts`にマイリストのCRUD用TanStack Queryフック（`useMyListsQuery`, `useCreateMyListMutation`, `useAddItemToMyListMutation`, `useRemoveItemFromMyListMutation`等）を実装し、`pages/MyListsPage.tsx`で任意名称のリスト作成・リストへのアイテム追加・削除を行うUIを実装する（REQ-009）。

## 依存タスク

- **前提タスク**: TASK-0005（apiClient実装）
- **後続タスク**: なし

## 完了条件

- [ ] `useMyListsQuery()`が`GET /mylists`相当を呼び出しリスト一覧を取得する
- [ ] `useMyListQuery(id)`が`GET /mylists/:id`相当を呼び出しリスト詳細（含まれるアイテム）を取得する
- [ ] `useCreateMyListMutation()`が`POST /mylists`を呼び出し、成功時にリスト一覧クエリを無効化する
- [ ] `useAddItemToMyListMutation()`が`POST /mylists/:id/items`を呼び出し、成功時に対象リスト詳細クエリを無効化する
- [ ] `useRemoveItemFromMyListMutation()`が`DELETE /mylists/:id/items/:item_id`を呼び出し、成功時に対象リスト詳細クエリを無効化する
- [ ] `MyListsPage`で任意の名称を入力してリストを新規作成できる
- [ ] `MyListsPage`でリストにアイテムを追加・削除できる

## 実装詳細

### 1. fetch関数・Queryフックの実装 🔵
**信頼性**: 🔵 *architecture.md「リソース別フック」・interfaces.ts MyListより*

`fetchMyLists(): Promise<MyList[]>`, `fetchMyList(id: string): Promise<MyList & {items: Item[]}>`, `createMyList(name: string): Promise<MyList>`, `addItemToMyList(listId: string, itemId: string): Promise<void>`, `removeItemFromMyList(listId: string, itemId: string): Promise<void>`をTASK-0005の`apiClient`を用いて実装する。`queryKey`は`['mylists']`（一覧）/`['mylists', 'detail', id]`（詳細）とする。

**実装ファイル**: `frontend/src/api/mylists.ts`

### 2. ミューテーション実装とキャッシュ無効化 🔵
**信頼性**: 🔵 *dataflow.md「データ整合性の保証」キャッシュ無効化方針より*

`useCreateMyListMutation`の`onSuccess`で`['mylists']`を無効化する。`useAddItemToMyListMutation`/`useRemoveItemFromMyListMutation`の`onSuccess`で`['mylists', 'detail', listId]`を無効化する。

**実装ファイル**: `frontend/src/api/mylists.ts`

### 3. MyListsPageの実装 🔵
**信頼性**: 🔵 *REQ-009・architecture.md 画面構成「/mylists」より*

react-hook-form + zodでリスト名入力フォームを構築する（任意名称、空文字は不可）。リスト一覧をサイドバーまたはタブで切り替え表示し、選択中のリストに含まれるアイテムをカード表示する。各アイテムカードに削除（リストから外す）ボタンを設置し、アイテム追加は既存アイテムからの選択UI（検索・選択モーダル等）で行う。

**実装ファイル**: `frontend/src/pages/MyListsPage.tsx`

## 単体テスト要件

### テストケース1: useCreateMyListMutationが成功時にリスト一覧を無効化する 🔵
**Given** 有効な`name`
**When** `mutate({name})`を実行し成功する
**Then** `queryClient.invalidateQueries`が`queryKey:['mylists']`で呼ばれる

### テストケース2: useAddItemToMyListMutationが成功時に対象リスト詳細を無効化する 🔵
**Given** 既存の`listId`と追加対象`itemId`
**When** `mutate({listId, itemId})`を実行し成功する
**Then** `queryClient.invalidateQueries`が`queryKey:['mylists', 'detail', listId]`で呼ばれる

### テストケース3: useRemoveItemFromMyListMutationが成功時に対象リスト詳細を無効化する 🔵
**Given** リストに含まれる`itemId`
**When** `mutate({listId, itemId})`を実行し成功する
**Then** `queryClient.invalidateQueries`が`queryKey:['mylists', 'detail', listId]`で呼ばれる

### テストケース4: MyListsPageでリスト作成フォームを送信すると新規リストが一覧に追加される 🔵
**Given** `MyListsPage`を開きリスト名を入力する
**When** 作成ボタンを押す
**Then** `useCreateMyListMutation`が呼ばれ、成功後にリスト一覧に新規リストが表示される

### テストケース5: MyListsPageでアイテム削除ボタンを押すとリストからアイテムが除外される 🟡
**Given** アイテムを含むリストを選択中
**When** アイテムカードの削除ボタンを押す
**Then** `useRemoveItemFromMyListMutation`が呼ばれ、成功後に当該アイテムが表示一覧から消える 🟡 *UI操作の具体フローは要件未記載のため一般的なパターンから推測*
