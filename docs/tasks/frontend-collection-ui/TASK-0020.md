## 背景・目的

詳細画面・編集画面では、配信サイトリンク（`item_links`）・ファイル（`item_files`）・トレーラーURL（`item_trailers`）の追加・編集・削除UIを提供する必要がある。ファイル種別がPDFの場合はCalibre-Webとの`calibre_book_id`紐付け状態を表示し、紐付け済みであればCalibre-Web閲覧URLへのリンクを表示する。本タスクではCRUD UIと表示分岐を実装し、後続のTASK-0021（アップロード機能本体）の土台となるリスト表示・編集UIを構築する。

## 実装詳細

### 対象ファイル

- `src/api/links-files.ts`（新規）: item_links/item_files/item_trailersのCRUDフック
- `src/features/links-files/LinksFilesSection.tsx`（新規）: 詳細画面に組み込む親セクション
- `src/features/links-files/ItemLinksList.tsx`（新規）: 配信サイトリンクのCRUD UI
- `src/features/links-files/ItemFilesList.tsx`（新規）: ファイル一覧UI（pdf/calibre連携表示含む）
- `src/features/links-files/ItemTrailersList.tsx`（新規）: トレーラーURLのCRUD UI
- `src/features/links-files/CalibreLinkBadge.tsx`（新規）: calibreBookId紐付け状態表示・閲覧リンク

### API要件

- 🔵 **REQ-011**: `src/api/links-files.ts`に`item_links`/`item_files`/`item_trailers`のCRUDフック（`useItemLinksQuery`, `useCreateItemLinkMutation`, `useDeleteItemLinkMutation`等、files/trailersも同様パターン）を実装する。
  *出典: requirements.md REQ-011*

### 機能要件対応

- 🔵 **REQ-011**: 詳細画面・編集画面で配信サイトリンク・ファイル・トレーラーURLの追加・編集・削除UIを提供する。各リストはshadcn/uiのリスト/テーブルコンポーネントで構成する。
  *出典: requirements.md REQ-011*
- 🟡 **REQ-105**: `item_files`の`fileType`が`pdf`の場合、`CalibreLinkBadge`で`calibreBookId`の紐付け状態を表示する。`calibreBookId`が設定済みであればCalibre-Web閲覧URL（バックエンド`PATCH /items/:id/files/:file_id/calibre-link`完了後の状態を前提とする）へのリンクを表示する。未紐付けの場合は「未連携」等のバッジを表示する。
  *出典: requirements.md REQ-105（バックエンドapi-endpoints.md PATCH /items/:id/files/:file_id/calibre-linkからの妥当な推測）*
- 🟡 **REQ-302**: 詳細画面にCalibre-Webへの直接遷移ボタンを表示してもよい（オプション要件）。本タスクでは`item_files`中にpdfかつ`calibreBookId`紐付け済みのファイルが存在する場合のみ、詳細画面ヘッダー付近に遷移ボタンを表示する形で最小実装する。
  *出典: requirements.md REQ-302（オプション要件、ルートPRD.md記述からの妥当な推測）*

### 表示分岐ロジック

```tsx
// ItemFilesList.tsx 概念コード
{file.fileType === 'pdf' && (
  file.calibreBookId
    ? <CalibreLinkBadge status="linked" calibreBookId={file.calibreBookId} />
    : <CalibreLinkBadge status="unlinked" />
)}
```

## テスト要件

### 単体テスト

- リンク（`item_links`）の追加・編集・削除のCRUD動作を確認する 🔵
- トレーラー（`item_trailers`）の追加・編集・削除のCRUD動作を確認する 🔵
- ファイル種別が`pdf`かつ`calibreBookId`が設定済みの場合、Calibre-Web閲覧リンクが表示されることを確認する 🟡
- ファイル種別が`pdf`かつ`calibreBookId`が未設定の場合、「未連携」表示になり閲覧リンクが表示されないことを確認する 🟡
- ファイル種別が`pdf`以外の場合、Calibre連携表示自体が出ないことを確認する 🔵

本タスク単独では対象外。TASK-0021（アップロード機能）との結合後にファイル追加→一覧反映のE2E相当フローを確認する。
