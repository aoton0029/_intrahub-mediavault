## 実装詳細

### MediaCard 🔵
**信頼性**: 🔵 *architecture.md「コンポーネント粒度」に明記。requirements.md REQ-001「全体一覧画面で、コレクション全体をカード/リスト表示」より用途を確認*

一覧画面（HomePage/GeneralListPage/AcademicListPage/PaperListPage）でアイテム1件をカード表示するコンポーネント。`interfaces.ts`の`Item`型を受け取り、`coverImageUrl`, `title`, `mediaType`（→`MediaTypeBadge`表示）, `isFavorite`, `status`を表示する。

```tsx
interface MediaCardProps {
  item: Item;
  onClick?: (item: Item) => void;
}
```

props構造自体はinterfaces.tsの`Item`型から導出されるため🔵。クリックハンドラの形・カード内の具体的なレイアウトは設計文書に明記がないため🟡妥当な推測。

### MediaTypeBadge 🔵
**信頼性**: 🔵 *architecture.md「コンポーネント粒度」、TASK-0002のmedia_type別アクセントカラー定義より*

`MediaType`を受け取り、対応する色・ラベルでバッジ表示する。

```tsx
interface MediaTypeBadgeProps {
  mediaType: MediaType;
}
```

8種別（anime/movie/drama/manga/novel/game/academic_book/paper）すべてに対応する日本語ラベル（例: anime→「アニメ」）は設計文書に明記がないため🟡妥当な推測。

### FilterBar（枠のみ） 🔵
**信頼性**: 🔵 *architecture.md「コンポーネント粒度」に明記。要件REQ-002/003は🔵だが、詳細UIはPhase2のため本タスクでは枠のみ*

本タスクでは絞り込みUIの詳細実装（media_type/タグ/カテゴリ/お気に入り/status選択UI）は行わず、後続フック`useSearchParamsFilter`（TASK-0008）と接続するための器（コンテナコンポーネント・props/children構成）のみを用意する。

```tsx
interface FilterBarProps {
  children?: React.ReactNode;
}
```

詳細フィルタUIの実装はPhase 2（TASK-0010想定、本タスク文書内では言及のみ）で行う。

### EmptyState 🟡
**信頼性**: 🟡 *requirements.md EDGE-101「アイテムが0件の場合、一覧画面は空状態（Empty State）として『コレクションがありません』等のメッセージと追加画面への導線を表示しなければならない」より、コンポーネント自体の存在はarchitecture.md「コンポーネント粒度」に明記（🔵）だが具体的なprops構成は推測*

```tsx
interface EmptyStateProps {
  message: string;
  actionLabel?: string;
  onAction?: () => void;
}
```

### ConfirmDialog 🟡
**信頼性**: 🟡 *architecture.md「コンポーネント粒度」にコンポーネント名は🔵明記。アイテム削除（REQ-007）・マイリスト削除・タグ削除等の確認ダイアログ用途として汎用的に必要と推測されるが、具体的なprops構成は設計文書に明記なし*

```tsx
interface ConfirmDialogProps {
  open: boolean;
  title: string;
  description?: string;
  onConfirm: () => void;
  onCancel: () => void;
  confirmLabel?: string;
  cancelLabel?: string;
}
```

shadcn/uiの`Dialog`をベースに実装する。状態管理（open/close）は呼び出し側または`useConfirmDialog`（TASK-0008）と組み合わせる想定。

## 単体テスト要件

### MediaCard: レンダリングとprops反映 🔵
**信頼性**: 🔵 *interfaces.ts Item型・完了条件より*
- `item`propsの`title`がレンダリング結果に表示されること
- `mediaType`に応じて`MediaTypeBadge`が表示されること
- `onClick`が渡された場合、カードクリックで呼び出されること

### MediaTypeBadge: レンダリングとprops反映 🔵
**信頼性**: 🔵 *MediaType型8種別より*
- 8種別すべての`mediaType`に対してエラーなくレンダリングされること
- `mediaType`に応じて異なるCSSクラス（アクセントカラー）が適用されること

### FilterBar: レンダリング 🟡
**信頼性**: 🟡 *本タスクでは枠のみのため最小限のテスト*
- `children`が正しくレンダリングされること

### EmptyState: レンダリングとprops反映 🟡
**信頼性**: 🟡 *EDGE-101から妥当な推測*
- `message`が表示されること
- `actionLabel`+`onAction`が渡された場合、ボタンクリックで`onAction`が呼ばれること

### ConfirmDialog: コールバック動作 🟡
**信頼性**: 🟡 *一般的なダイアログパターンから妥当な推測*
- `open=true`のとき内容が表示され、`open=false`のとき表示されないこと
- 確認ボタンクリックで`onConfirm`が呼ばれること
- キャンセルボタンクリックで`onCancel`が呼ばれること
