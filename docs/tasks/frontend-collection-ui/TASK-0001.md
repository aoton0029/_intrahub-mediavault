## タスク概要

`frontend/`配下のVite + React + TypeScriptスケルトン（note.md「実装状況」記載: `yarn create vite . --template react-ts`直後）に、本プロジェクトで採用が確定している依存パッケージを追加し、ビルド・テスト・Lintの実行基盤を整備する。react-router-dom v7, @tanstack/react-query v5, react-hook-form, zod, sonner, shadcn/ui（components.json初期化）, Tailwind CSS v4, Vitest + @testing-library/react + jsdom, Playwright を導入し、package.jsonのスクリプト（dev/build/test/test:e2e/lint）を整備する。

## 実装詳細

### パッケージ追加 🔵
**信頼性**: 🔵 *note.md「技術スタック」・architecture.md「フロントエンド全体構成」より*

`frontend/`にて以下を追加する。

- ランタイム依存: `react-router-dom@^7`, `@tanstack/react-query@^5`, `react-hook-form`, `zod`, `sonner`
- 開発依存: `vitest`, `@testing-library/react`, `@testing-library/jest-dom`, `jsdom`, `@playwright/test`
- shadcn/ui: `npx shadcn@latest init`相当のコマンドでcomponents.json生成（スタイル: 後続TASK-0002のダークテーマトークンと整合させるためCSS変数モードを選択）

note.mdではパッケージマネージャはpnpm想定（🔵 note.md「技術スタック」より）だが、既存`frontend/`内に別マネージャのロックファイルがある場合は既存方式を優先する（🟡 実機確認が必要なため推測）。

### Tailwind CSS v4設定 🔵
**信頼性**: 🔵 *architecture.md「UIライブラリ」より、Tailwind CSS 4 + shadcn/uiを採用*

`@tailwindcss/vite`プラグイン方式（Tailwind v4標準）で`vite.config.ts`に追加し、`src/index.css`に`@import "tailwindcss";`を記述する。詳細なデザイントークン定義はTASK-0002で行うため、本タスクではビルド経路の確立のみを行う。

### テスト基盤設定 🔵
**信頼性**: 🔵 *note.md「技術スタック」（Vitest + Testing Library / Playwright）より*

- `vitest.config.ts`（または`vite.config.ts`の`test`フィールド）でjsdom環境・グローバルAPI（`describe`/`it`/`expect`）を設定
- `src/test/setup.ts`で`@testing-library/jest-dom`のマッチャーを登録し、`vitest.config.ts`の`setupFiles`に指定
- Playwrightは`tests/e2e/`配下を対象に設定（🟡 ディレクトリ名はarchitecture.mdの`tests/`記載から妥当な推測）

### package.jsonスクリプト整備 🟡
**信頼性**: 🟡 *一般的なVite+Vitest+Playwrightプロジェクト構成から妥当な推測（設計文書に個別スクリプト名の記載なし）*

```json
{
  "scripts": {
    "dev": "vite",
    "build": "tsc -b && vite build",
    "lint": "eslint .",
    "test": "vitest run",
    "test:watch": "vitest",
    "test:e2e": "playwright test"
  }
}
```
