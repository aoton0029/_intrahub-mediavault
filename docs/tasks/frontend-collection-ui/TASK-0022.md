## 実装内容

### 1. zodスキーマ定義 🔵

**信頼性**: 🔵 *interfaces.ts CreateItemRequest/UpdateItemRequest・architecture.md「フォーム」節より*

`src/lib/itemSchema.ts` に以下のzodスキーマを定義する。

- `createItemRequestSchema`: `CreateItemRequest`（interfaces.ts 300-311行目）に対応するzodスキーマ
  - `mediaType`: `z.enum([...MediaType候補])` 必須
  - `title`: `z.string().min(1)` 必須
  - `originalTitle`: `z.string().optional()`
  - `description`: `z.string().optional()`
  - `coverImageUrl`: `z.string().url().optional().or(z.literal(''))`
  - `releaseDate`: ISO日付文字列（`YYYY-MM-DD`）の正規表現または`z.string().optional()`、不正形式を拒否
  - `homepageUrl`: `z.string().url().optional().or(z.literal(''))`
  - `source`: `z.enum(['api', 'manual'])` 必須
  - `externalId`: `z.string().optional()`（source==='api'のときのみ意味を持つが、スキーマ上はoptional 🟡 REQ-201/202からの妥当な推測）
  - `details`: `z.record(z.unknown())`（メディア別詳細は後続TASK-0023/0024/0025で各メディア別スキーマと`.merge()`/`.extend()`して利用）
- `updateItemRequestSchema`: `UpdateItemRequest`（interfaces.ts 314-321行目）に対応するzodスキーマ。全項目`.optional()`（PATCH想定）
  - `title?`, `description?`, `status?`（`ItemStatus`のenum）, `consumedDate?`, `rating?`（数値範囲、例: 0-10 🟡 PRD/要件に数値範囲記載なし、妥当推測）, `isFavorite?`

### 2. 共通フォーム部品（ItemBase項目） 🔵

**信頼性**: 🔵 *interfaces.ts ItemBase（125-142行目）・architecture.md react-hook-form+zod採用方針より*

`src/features/item-form/components/ItemBaseFields.tsx` を実装する。react-hook-formの`useFormContext`を用い、以下のItemBase共通項目の入力UIを提供する。

- タイトル（必須、`<Input>`）
- 原題（任意）
- 説明（任意、`<Textarea>`）
- カバー画像URL（任意、URL形式バリデーション、入力時にプレビュー表示 🟡 一般的なUXパターンから推測）
- 公開日（任意、日付input）
- 公式サイトURL（任意、URL形式バリデーション）

shadcn/uiの`Form`, `FormField`, `FormItem`, `FormLabel`, `FormControl`, `FormMessage`コンポーネントを使用し、エラー時はフィールド近傍に表示する（NFR-201）。

## 単体テスト要件 🔵

**信頼性**: 🔵 *NFR-201・REQ-006/007より*

- `createItemRequestSchema`
  - 必須項目（`mediaType`, `title`, `source`）が欠落している場合に検証エラーとなること
  - `title`が空文字の場合に拒否されること
  - `coverImageUrl`/`homepageUrl`に不正なURL文字列を渡した場合に拒否されること
  - `releaseDate`に`YYYY-MM-DD`以外の形式を渡した場合に拒否されること
  - 全項目が正しい場合にパースが成功すること
- `updateItemRequestSchema`
  - 空オブジェクト（全項目未指定）でもパースが成功すること（PATCH想定）
  - `status`に`ItemStatus`以外の値を渡した場合に拒否されること
- `ItemBaseFields`コンポーネント
  - 各フィールドが表示されること
  - 不正な値を入力しsubmitした際にフィールド近傍にエラーメッセージが表示されること
