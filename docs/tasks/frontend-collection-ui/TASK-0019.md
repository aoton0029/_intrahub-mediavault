## 背景・目的

詳細画面では、他メディアアイテムへの関連付け（`item_relations`）を追加・削除できる必要がある。特にゲームの場合はDLC/拡張パックを`relation_type=dlc`で関連付け、本体作品の詳細画面でDLC一覧として表示する必要がある（REQ-018/103）。本タスクでは関連付けの汎用UIとAPIフックを実装する。

## 実装詳細

### 対象ファイル

- `src/api/relations.ts`（新規）: 関連付けCRUDフック
- `src/features/relations/RelationsSection.tsx`（新規）: 詳細画面に組み込む関連付けセクション
- `src/features/relations/RelationPickerDialog.tsx`（新規）: 他アイテムを検索・選択して関連付けるダイアログ
- `src/features/relations/DlcList.tsx`（新規）: game専用、relation_type=dlcのみの一覧表示

### API要件

- 🔵 **REQ-010**: `POST /item-relations`, `DELETE /item-relations`による関連付けの追加・削除フックを`src/api/relations.ts`に実装する。
  *出典: requirements.md REQ-010*
- 🔵 `useCreateItemRelationMutation()`, `useDeleteItemRelationMutation()`を定義し、成功時は当該アイテムの詳細クエリ（`['items', itemId]`）を無効化して再取得する。
  *出典: interfaces.ts ItemRelation, architecture.md キャッシュ無効化方針（dataflow.md「データ整合性の保証」）*

### 機能要件対応

- 🔵 **REQ-010**: 詳細画面で他メディアアイテムへの関連付け追加（`RelationPickerDialog`で対象アイテムを検索・選択し`relationType='reference'`等で関連付け）・削除を行うUIを提供する。
  *出典: requirements.md REQ-010*
- 🔵 **REQ-018 / REQ-103**: `mediaType`が`game`の場合、`RelationsSection`は`DlcList`を表示し、`relationType=dlc`でフィルタした関連アイテム一覧を表示する。DLC一覧は本体作品からの一方向参照として表示する。
  *出典: requirements.md REQ-018, REQ-103*

### コンポーネント構成

```tsx
// RelationsSection.tsx 概念コード
{item.mediaType === 'game' && <DlcList itemId={item.id} />}
<GeneralRelationsList itemId={item.id} /> {/* relation_type=referenceの汎用関連付け一覧 */}
```

🟡 *gameのみDLC一覧を専用表示し、他メディアでも汎用の関連付け一覧（reference）は共通で表示する設計。要件には「他メディアのアイテムへの関連付け」という汎用表現のみで、表示UIの詳細レイアウトはPRD未記載のため妥当な推測。*
