## タスク概要
backend/Cargo.toml の Cargo workspace に新規クレート `mediavault-api` を追加し、本プロジェクトで使用する全依存パッケージ（Axum、sqlx、serde系、uuid、chrono、dotenvy等）を設定する。既存の `api-client-lib` クレートを path 依存として `mediavault-api` から参照できるようにし、以降のフェーズで外部APIクライアント（ApiClient トレイト）を呼び出せる土台を整える。

## 実装詳細
### 1. workspaceメンバー追加 🔵
**信頼性**: 🔵 *tech-stack.md「推奨ディレクトリ構造」より*
`backend/Cargo.toml` の `[workspace] members = [...]` に `"mediavault-api"` を追加する。既存メンバーである `api-client-lib` の定義は変更しない。
**実装ファイル**: `backend/Cargo.toml`

### 2. mediavault-apiクレート初期化 🔵
**信頼性**: 🔵 *tech-stack.md・architecture.mdの構成方針より*
`backend/mediavault-api/` ディレクトリと `Cargo.toml`、`src/main.rs`（最小限の `fn main() {}` でよい。本格実装はTASK-0007）を作成する。
**実装ファイル**: `backend/mediavault-api/Cargo.toml`, `backend/mediavault-api/src/main.rs`

### 3. 依存パッケージ設定 🔵
**信頼性**: 🔵 *tech-stack.md記載の技術スタック一覧より*
以下を `mediavault-api/Cargo.toml` の `[dependencies]` に追加する。
- `axum`（Webフレームワーク）
- `tokio`（`features = ["full"]`、非同期runtime）
- `sqlx`（`features = ["postgres", "runtime-tokio", "macros", "chrono", "uuid"]`）
- `serde`（`features = ["derive"]`）, `serde_json`
- `uuid`（`features = ["v4", "serde"]`）
- `chrono`（`features = ["serde"]`）
- `dotenvy`（`.env`読込）
- `tracing`, `tracing-subscriber`（ログ。🟡 既存実装なしのため一般的構成からの妥当な推測）
**実装ファイル**: `backend/mediavault-api/Cargo.toml`

### 4. api-client-lib のpath依存追加 🔵
**信頼性**: 🔵 *「backend/api-client-lib に外部APIクライアント実装済み」という前提より*
`mediavault-api/Cargo.toml` に `api-client-lib = { path = "../api-client-lib" }` を追加し、`cargo build` で解決できることを確認する。
**実装ファイル**: `backend/mediavault-api/Cargo.toml`
