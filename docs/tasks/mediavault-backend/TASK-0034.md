## タスク概要
`backend/README.md`を整備し、新規開発者・運用者がローカル環境を構築して`mediavault-api`を起動できるようにする。`docker compose up`によるPostgreSQL起動、`sqlx migrate run`によるスキーマ適用、`cargo run`によるAPIサーバー起動の手順を明文化し、`.env.example`を作成して必要な環境変数（内部APIキー、DB接続情報、外部APIキー類）を一覧化する。さらに、内部APIキーの設定方法と、TMDb/IGDB/Steam等の外部APIキーを`PUT /settings/api-keys/{provider}`で登録する手順も記載する。

## 実装詳細
### 1. 開発環境セットアップ手順 🟡
**信頼性**: 🟡 *prep.md「必須」セクション・tech-stack.md「開発環境」から妥当な推測（README自体は未作成のため新規構成）*
前提ソフトウェア（Docker, Rust toolchain, sqlx-cli）のインストール案内に続き、以下の順序を記載する。
1. `docker compose up -d`（PostgreSQLコンテナ起動）
2. `.env.example`を`.env`にコピーし、必要な値を設定
3. `sqlx migrate run`（DATABASE_URLを参照してマイグレーション適用）
4. `cargo run`（APIサーバー起動）

**実装ファイル**: `backend/README.md`

### 2. .env.example の作成 🔵
**信頼性**: 🔵 *prep.md「内部REST API用APIキーの発行」、architecture.mdのDB接続設定より*
`DATABASE_URL`（Postgres接続文字列）、`INTERNAL_API_KEY`（内部REST API認証キー）、サーバーバインドアドレス・ポート、ファイルサーバーのマウントパス（`/srv/files/pdf`, `/srv/media/photos`）に対応する環境変数をコメント付きで列挙する。外部APIキー（TMDb/IGDB等）はDB管理（`api_credentials`テーブル）のためREADME本文側で案内し、`.env.example`には含めない方針とする。

**実装ファイル**: `backend/.env.example`

### 3. APIキー設定方法の記載 🔵
**信頼性**: 🔵 *acceptance-criteria.md REQ-015/NFR-202、REQ-018/REQ-403より*
内部APIキーは`.env`の`INTERNAL_API_KEY`に設定し、全リクエストの`Authorization: Bearer {key}`ヘッダーに付与する旨を記載する。外部APIキー（TMDb, IGDB, Steam等）は`PUT /settings/api-keys/{provider}`にキー文字列をJSONで送信して登録する手順をcurl例付きで記載し、各providerのキー取得先（prep.md記載のTMDb/IGDB/Steam Web APIの取得URL）へのリンクを含める。

**実装ファイル**: `backend/README.md`

### 4. ファイルサーバーディレクトリ設定の記載 🔵
**信頼性**: 🔵 *prep.md「ファイルサーバー用ディレクトリの準備」、acceptance-criteria.md REQ-007/REQ-019より*
`/srv/files/pdf`（PDF用）・`/srv/media/photos`（画像用）をdocker composeのボリュームマウントとして設定する例を記載し、ローカル開発時は任意のローカルディレクトリで代替できることを補足する。

**実装ファイル**: `backend/README.md`, `docker-compose.yml`（マウント例の参照のみ、既存ファイルへの追記は必要時のみ）
