## タスク概要
スタッフ（`staff`）の作成と、itemへのスタッフ紐付け（`item_staff`、role・character_name付き）のCRUDを実装する。`POST /staff`, `POST /items/:id/staff`, `DELETE /items/:id/staff/:item_staff_id`を構築する。

## 依存タスク
- **前提タスク**: TASK-0004（マイグレーション）, TASK-0007（起動骨格）
- **後続タスク**: なし

## 完了条件
- [ ] `POST /staff`が`name`, `external_id`(optional), `image_url`(optional)を受け取り、`staff`テーブルに作成する
- [ ] `POST /items/:id/staff`が`staff_id`, `role`, `character_name`(optional)を受け取り、`item_staff`にINSERTする
- [ ] `DELETE /items/:id/staff/:item_staff_id`が`item_staff.id`を指定して該当紐付けを削除する
- [ ] 存在しない`staff_id`を指定した場合、`STAFF_NOT_FOUND`（404）を返す
- [ ] 存在しない`item_staff_id`を指定して削除した場合、404を返す

---
## 実装詳細

### 1. POST /staff ハンドラ実装 🔵
**信頼性**: 🔵 *REQ-009・user-stories 4.1より*

`mediavault-api/src/handlers/staff.rs`に`create_staff`を実装する。`staff`テーブル（`id`, `external_id`, `name`, `image_url`, `created_at`）にINSERTする。

**実装ファイル**: `mediavault-api/src/handlers/staff.rs`, `mediavault-api/src/models/staff.rs`

### 2. POST /items/:id/staff ハンドラ実装 🔵
**信頼性**: 🔵 *api-endpoints.md POST /items/:id/staff リクエスト例より*

```json
{ "staff_id": "...", "role": "監督", "character_name": null }
```
`item_staff`（`id`, `item_id`, `staff_id`, `role`, `character_name`）にINSERTする。`item_id`, `staff_id`の存在を事前確認する。

**実装ファイル**: `mediavault-api/src/handlers/staff.rs`

### 3. DELETE /items/:id/staff/:item_staff_id ハンドラ実装 🟡
**信頼性**: 🟡 *REQ-009「紐付け」から妥当な推測（api-endpoints.mdでも🟡）*

`item_staff.id`を主キーとしてDELETEする。`item_id`との整合性チェック（指定された`item_id`に属する`item_staff_id`であること）も行う。

**実装ファイル**: `mediavault-api/src/handlers/staff.rs`

## 単体テスト要件

### テストケース1: スタッフ作成の正常動作 🔵
**Given** `{ "name": "監督A" }`
**When** `POST /staff`を呼び出す
**Then** 201でスタッフ（UUID付き）が返る

### テストケース2: itemへのスタッフ紐付け 🔵
**Given** 既存item, 既存staff, `{ "staff_id": "...", "role": "監督" }`
**When** `POST /items/:id/staff`を呼び出す
**Then** 201で`item_staff`にレコードが作成される

### テストケース3: character_name付きの紐付け（声優役） 🟡
**Given** `{ "staff_id": "...", "role": "声優", "character_name": "主人公" }`
**When** `POST /items/:id/staff`を呼び出す
**Then** `character_name`が正しく保存される

### テストケース4: 紐付け削除の正常動作 🟡
**Given** 既存の`item_staff`レコード
**When** `DELETE /items/:id/staff/:item_staff_id`を呼び出す
**Then** 204でレコードが削除される

### テストケース5: 存在しないstaff_idでの紐付けで404 🟡
**Given** 存在しないstaff UUID
**When** `POST /items/:id/staff`を呼び出す
**Then** 404 `STAFF_NOT_FOUND`が返る
