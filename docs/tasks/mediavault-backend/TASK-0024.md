## タスク概要
`GET /items/search` エンドポイントを実装する。クエリパラメータ `media_type`（必須）・`q`（必須、検索語）を受け取り、TASK-0023で実装した `ExternalSearchService::search` を呼び出して外部API検索結果を返す。`ExternalSearchService` が返すエラー種別に応じて、APIキー未設定時は `422 API_KEY_NOT_CONFIGURED`、外部APIタイムアウト等のエラー時は `502 EXTERNAL_API_TIMEOUT` を返すようにハンドラ層でマッピングする。

## 実装詳細
### 1. クエリパラメータDTO定義 🔵
**信頼性**: 🔵 *api-endpoints.md GET /items/search「クエリパラメータ: media_type（必須）, q（必須、検索語）」より*
```rust
#[derive(Debug, Deserialize)]
pub struct ItemSearchQuery {
    pub media_type: MediaType,
    pub q: String,
}
```
Axumの `Query<ItemSearchQuery>` extractorでデシリアライズに失敗した場合（必須パラメータ欠落・media_type不正値）は `400 VALIDATION_ERROR` を返す。
**実装ファイル**: `backend/mediavault-api/src/models/item_search.rs`

### 2. ハンドラ実装 🔵
**信頼性**: 🔵 *architecture.md レイヤードアーキテクチャ（routes→handlers→services）方針より*
`handlers::items::search_items` で `ExternalSearchService::search(media_type, &q)` を呼び出し、`Ok`時は `200`で結果配列を返す。
**実装ファイル**: `backend/mediavault-api/src/handlers/items.rs`

### 3. エラーマッピング 🔵
**信頼性**: 🔵 *api-endpoints.md「API_KEY_NOT_CONFIGURED（422, TC-002-E01, EDGE-001）」「EXTERNAL_API_TIMEOUT（502, TC-002-E02）」より*
`ExternalSearchError::ApiKeyNotConfigured` → `AppError`実装で `422 API_KEY_NOT_CONFIGURED`、`ExternalSearchError::ExternalApiError` → `502 EXTERNAL_API_TIMEOUT` にマッピングする `impl From<ExternalSearchError> for AppError`（または同等のエラー変換実装）を追加する。
**実装ファイル**: `backend/mediavault-api/src/errors.rs`（または`handlers/items.rs`内）

### 4. ルーティング登録 🔵
**信頼性**: 🔵 *api-endpoints.md「### 外部API検索・インポート」節より*
`GET /items/search` を `routes/items.rs` に登録する。`/items/:id` 等の動的パスとの競合に注意し、`/items/search` を先に定義する（Axumのルーティング優先順位確認）。
**実装ファイル**: `backend/mediavault-api/src/routes/items.rs`

## 単体テスト要件
### テストケース1: anime検索でJikan結果が返る（TC-002-01） 🔵
**信頼性**: 🔵 *acceptance-criteria.md TC-002-01より*
**Given**: `ExternalSearchService`（モック）が`media_type=anime`に対して検索結果配列を返すよう設定
**When**: `GET /items/search?media_type=anime&q=鬼滅`
**Then**: `200`が返り、レスポンスボディにJikanの検索結果一覧が含まれる

### テストケース2: movie/drama検索でTMDb結果が返る（TC-002-02） 🔵
**信頼性**: 🔵 *acceptance-criteria.md TC-002-02より*
**Given**: `ExternalSearchService`（モック）が`media_type=movie`に対してTMDb検索結果を返すよう設定
**When**: `GET /items/search?media_type=movie&q=タイトル`
**Then**: `200`が返り、TMDbの検索結果一覧が含まれる

### テストケース3: APIキー未登録時に422（TC-002-E01） 🟡
**信頼性**: 🟡 *acceptance-criteria.md TC-002-E01（信頼性🟡指定）・EDGE-001より*
**Given**: `ExternalSearchService`が`ApiKeyNotConfigured`エラーを返すモック
**When**: `GET /items/search?media_type=movie&q=タイトル`
**Then**: `422`が返り、エラーコードは`API_KEY_NOT_CONFIGURED`

### テストケース4: 外部APIタイムアウト時に502（TC-002-E02） 🟡
**信頼性**: 🟡 *acceptance-criteria.md TC-002-E02（信頼性🟡指定）より*
**Given**: `ExternalSearchService`が`ExternalApiError`エラーを返すモック
**When**: `GET /items/search?media_type=movie&q=タイトル`
**Then**: `502`が返り、エラーコードは`EXTERNAL_API_TIMEOUT`であり、プロセスはpanicしない

### テストケース5: 必須パラメータ欠落時に400 🟡
**信頼性**: 🟡 *api-endpoints.md「クエリパラメータ必須」記載から妥当な推測（個別TCの明記なし）*
**Given**: `q`パラメータを省略
**When**: `GET /items/search?media_type=anime`
**Then**: `400 VALIDATION_ERROR`が返る
