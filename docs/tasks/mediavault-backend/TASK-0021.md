## タスク概要
`item_links`（参考リンク）および`item_trailers`（トレーラー動画リンク）のCRUDを実装する。`POST/DELETE /items/:id/links/:link_id`, `POST/DELETE /items/:id/trailers/:trailer_id`を構築する。

## 依存タスク
- **前提タスク**: TASK-0004（マイグレーション）, TASK-0007（起動骨格）
- **後続タスク**: なし

## 完了条件
- [x] `POST /items/:id/links`が`url`(必須), `label`(必須)を受け取り、`item_links`にINSERTする
- [x] `DELETE /items/:id/links/:link_id`が指定リンクを削除する
- [x] `POST /items/:id/trailers`が`url`(必須), `label`(optional)を受け取り、`item_trailers`にINSERTする
- [x] `DELETE /items/:id/trailers/:trailer_id`が指定トレーラーを削除する
- [x] `url`が空文字の場合、`VALIDATION_ERROR`（400）を返す
- [x] 該当itemが存在しない場合、`ITEM_NOT_FOUND`（404）を返す

---
## 実装詳細

### 1. item_links CRUDハンドラ実装 🔵
**信頼性**: 🔵 *api-endpoints.md POST/DELETE /items/:id/links/:link_id より*

`mediavault-api/src/handlers/item_links.rs`に`create_item_link`, `delete_item_link`を実装する。`item_links`テーブル（`id`, `item_id`, `url`, `label`, `created_at`）にINSERT/DELETEする。

**実装ファイル**: `mediavault-api/src/handlers/item_links.rs`, `mediavault-api/src/models/item_link.rs`

### 2. item_trailers CRUDハンドラ実装 🔵
**信頼性**: 🔵 *api-endpoints.md POST/DELETE /items/:id/trailers/:trailer_id より*

`mediavault-api/src/handlers/item_trailers.rs`に`create_item_trailer`, `delete_item_trailer`を実装する。`item_trailers`テーブル（`id`, `item_id`, `url`, `label`, `created_at`）にINSERT/DELETEする。`label`はNULL許容。

**実装ファイル**: `mediavault-api/src/handlers/item_trailers.rs`, `mediavault-api/src/models/item_trailer.rs`

### 3. url バリデーション 🟡
**信頼性**: 🟡 *VARCHAR(1000) NOT NULL制約から妥当な推測（URL形式の厳密な検証はPRD未記載）*

`url`の非空チェックのみを行う（URL形式の厳密な検証は要件未記載のため対象外とする）。

**実装ファイル**: `mediavault-api/src/handlers/item_links.rs`, `mediavault-api/src/handlers/item_trailers.rs`

## 単体テスト要件

### テストケース1: リンク作成の正常動作 🔵
**Given** 既存item, `{ "url": "https://example.com", "label": "公式サイト" }`
**When** `POST /items/:id/links`を呼び出す
**Then** 201でリンク（UUID付き）が返る

### テストケース2: リンク削除の正常動作 🔵
**Given** 既存のitem_linkレコード
**When** `DELETE /items/:id/links/:link_id`を呼び出す
**Then** 204でレコードが削除される

### テストケース3: トレーラー作成の正常動作 🔵
**Given** 既存item, `{ "url": "https://youtube.com/xxx" }`
**When** `POST /items/:id/trailers`を呼び出す
**Then** 201でトレーラー（UUID付き）が返る

### テストケース4: url空文字で400 🟡
**Given** `{ "url": "" }`
**When** `POST /items/:id/links`を呼び出す
**Then** 400 `VALIDATION_ERROR`が返る
