## タスク概要
`item_episodes`テーブル（season/chapter配下のみ使用）のCRUDを実装する。`POST /groups/:group_id/episodes`による話数登録時、`group_type=volume`の場合はアプリケーション層で400を返し拒否する（EDGE-101）。DB層トリガー`trg_check_episode_group_type`との二重チェック構成。`GET /groups/:group_id/episodes`はepisode_number順で一覧取得する。

## 実装詳細

### 1. CreateItemEpisodeRequest DTO定義 🔵
**信頼性**: 🔵 *api-endpoints.md POST /groups/:group_id/episodes リクエスト例より*

```json
{ "episode_number": 1, "title": "第1話", "air_date": "2026-01-05" }
```
`episode_number`は必須。`title`, `original_title`, `air_date`, `description`はoptional。

**実装ファイル**: `mediavault-api/src/models/item_episode.rs`

### 2. group_type=volume検証（EDGE-101） 🔵
**信頼性**: 🔵 *EDGE-101「volume配下のグループへの登録はリクエストを拒否」、TC-010-E01/TC-EDGE-101-01より*

ハンドラ内で対象`group_id`の`item_groups.group_type`を事前にSELECTし、`volume`の場合は`INVALID_GROUP_TYPE_FOR_EPISODES`（400）をDBへのINSERT前に返す。

**実装ファイル**: `mediavault-api/src/handlers/item_episodes.rs`

### 3. DBトリガーエラーのハンドリング 🔵
**信頼性**: 🔵 *database-schema.sql trg_check_episode_group_typeより*

アプリケーション層チェックをすり抜けた場合（レース条件等）でも、DBトリガーが`RAISE EXCEPTION`を発生させる。このPostgresエラーをsqlxレベルでキャッチし、`INVALID_GROUP_TYPE_FOR_EPISODES`（400）にマッピングする。

**実装ファイル**: `mediavault-api/src/handlers/item_episodes.rs`, `mediavault-api/src/error.rs`

### 4. GET /groups/:group_id/episodes ハンドラ実装 🔵
**信頼性**: 🔵 *TC-010-02より*

`group_id`に紐づく`item_episodes`を`episode_number ASC`でソートして取得する。

**実装ファイル**: `mediavault-api/src/handlers/item_episodes.rs`

## 単体テスト要件

### テストケース1: TC-010-01 season配下への話数登録の正常動作 🔵
**Given** `group_type=season`のグループ
**When** `POST /groups/:group_id/episodes`を呼び出す
**Then** 201で話数レコードが返る

### テストケース2: TC-010-E01/TC-EDGE-101-01 volume配下への話数登録拒否 🔵
**Given** `group_type=volume`のグループ
**When** `POST /groups/:group_id/episodes`を呼び出す
**Then** 400 `INVALID_GROUP_TYPE_FOR_EPISODES`が返り、`item_episodes`にレコードが作成されない

### テストケース3: episode_number重複での一意制約違反 🟡
**Given** 既に`episode_number=1`が存在するグループ
**When** 同じ`episode_number=1`で`POST /groups/:group_id/episodes`を呼び出す
**Then** 一意制約違反に対応したエラー（400または409）が返る

### テストケース4: TC-010-02 episode一覧のepisode_number順取得 🔵
**Given** episode_numberが3,1,2の3話数
**When** `GET /groups/:group_id/episodes`を呼び出す
**Then** episode_number 1,2,3の順で返る
