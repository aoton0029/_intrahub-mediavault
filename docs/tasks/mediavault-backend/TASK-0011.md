## タスク概要
`GET /items/:id`エンドポイントを実装する。アイテムの詳細情報をメディア別詳細テーブル、タグ、カテゴリ等の関連データを含めて取得する。存在しないIDの場合は`ITEM_NOT_FOUND`（404）を返す。

## 依存タスク
- **前提タスク**: TASK-0008（itemsモデル・DTO）
- **後続タスク**: なし

## 完了条件
- [ ] `GET /items/:id`が指定UUIDの`items`レコードを取得する
- [ ] `media_type`に応じたメディア別詳細テーブルをJOINしてレスポンスに含める
- [ ] 紐づくタグ・カテゴリ一覧をレスポンスに含める
- [ ] 該当itemが存在しない場合、`ITEM_NOT_FOUND`（404）を返す
- [ ] 不正なUUID形式の場合、適切なエラー（400）を返す

---
## 実装詳細

### 1. GET /items/:id ハンドラ実装 🟡
**信頼性**: 🟡 *api-endpoints.md GET /items/:id（個別取得APIはPRDに直接記載なしのため推測）*

`mediavault-api/src/handlers/items.rs`に`get_item`ハンドラを実装し、パスパラメータからUUIDを取得する。

**実装ファイル**: `mediavault-api/src/handlers/items.rs`

### 2. メディア別詳細テーブルJOIN取得 🟡
**信頼性**: 🟡 *api-endpoints.md「メディア別詳細テーブル・タグ・関連付け等を含む」から妥当な推測*

`items`テーブルから`media_type`を取得後、対応する詳細テーブルに対して`item_id`でJOINクエリを実行する。media_typeごとに異なるテーブルへの分岐が必要なため、match式でクエリを切り替える。

**実装ファイル**: `mediavault-api/src/repositories/item_repository.rs`

### 3. ITEM_NOT_FOUND エラー処理 🔵
**信頼性**: 🔵 *api-endpoints.md エラーコード: ITEM_NOT_FOUND（404）より*

クエリ結果が0件の場合、共通エラー型の`ITEM_NOT_FOUND`（404）を返す。

**実装ファイル**: `mediavault-api/src/handlers/items.rs`, `mediavault-api/src/error.rs`

## 単体テスト要件

### テストケース1: 存在するitemの詳細取得 🟡
**Given** 既存のitem UUID
**When** `GET /items/:id`を呼び出す
**Then** 200でitem詳細（メディア別詳細含む）が返る

### テストケース2: 存在しないitemで404 🔵
**Given** 存在しないUUID
**When** `GET /items/:id`を呼び出す
**Then** 404 `ITEM_NOT_FOUND`が返る

### テストケース3: 不正なUUID形式で400 🟡
**Given** UUID形式でない文字列（例: "abc"）
**When** `GET /items/:id`を呼び出す
**Then** 400エラーが返る
