## タスク概要
`PATCH /items/:id/status`エンドポイントを実装する。視聴・読了状況（`status`）および消費日（`consumed_date`）を更新する専用エンドポイント。

## 依存タスク
- **前提タスク**: TASK-0008（itemsモデル・DTO）
- **後続タスク**: なし

## 完了条件
- [x] `PATCH /items/:id/status`が`status`(item_status enum), `consumed_date`(optional)を受け取る
- [x] `status`が`not_started`/`in_progress`/`completed`以外の場合、`VALIDATION_ERROR`（400）を返す
- [x] 該当itemが存在しない場合、`ITEM_NOT_FOUND`（404）を返す
- [x] 更新後のitemを200で返す

---
## 実装詳細

### 1. UpdateStatusRequest DTO定義 🔵
**信頼性**: 🔵 *api-endpoints.md PATCH /items/:id/status リクエスト例より*

```json
{ "status": "completed", "consumed_date": "2026-06-20" }
```
`status`は必須（`ItemStatus` enum）、`consumed_date`はoptional。

**実装ファイル**: `mediavault-api/src/models/item.rs`

### 2. PATCH /items/:id/status ハンドラ実装 🔵
**信頼性**: 🔵 *REQ-008・user-stories 1.5より*

`mediavault-api/src/handlers/items.rs`に`update_item_status`ハンドラを実装し、`items`テーブルの`status`, `consumed_date`カラムのみをUPDATEする。

**実装ファイル**: `mediavault-api/src/handlers/items.rs`

## 単体テスト要件

### テストケース1: statusとconsumed_dateの正常更新 🔵
**Given** 既存item, `{ "status": "completed", "consumed_date": "2026-06-20" }`
**When** `PATCH /items/:id/status`を呼び出す
**Then** 200で`status="completed"`, `consumed_date="2026-06-20"`に更新される

### テストケース2: status不正値で400 🟡
**Given** `{ "status": "invalid_status" }`
**When** `PATCH /items/:id/status`を呼び出す
**Then** 400 `VALIDATION_ERROR`が返る

### テストケース3: 存在しないitemで404 🟡
**Given** 存在しないUUID
**When** `PATCH /items/:id/status`を呼び出す
**Then** 404 `ITEM_NOT_FOUND`が返る
