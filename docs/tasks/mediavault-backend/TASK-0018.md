## タスク概要
`item_groups`テーブル（シーズン/巻/章の汎用グループモデル）のCRUDを実装する。`POST /items/:id/groups`によるグループ作成と、`GET /items/:id/groups`による`display_order`順での一覧取得を構築する。

## 依存タスク
- **前提タスク**: TASK-0004（マイグレーション）, TASK-0007（起動骨格）
- **後続タスク**: TASK-0019（item_episodes CRUD）

## 完了条件
- [ ] `POST /items/:id/groups`が`group_type`(season/volume/chapter), `group_name`, `number`, `display_order`を受け取り、`item_groups`にINSERTする
- [ ] `group_type`が不正な値の場合、`VALIDATION_ERROR`（400）を返す
- [ ] `parent_item_id`を指定した入れ子構造をサポートする
- [ ] `GET /items/:id/groups`が`display_order`昇順でグループ一覧を返す
- [ ] 該当itemが存在しない場合、`ITEM_NOT_FOUND`（404）を返す

---
## 実装詳細

### 1. CreateItemGroupRequest DTO定義 🔵
**信頼性**: 🔵 *api-endpoints.md POST /items/:id/groups リクエスト例より*

```json
{ "group_type": "season", "group_name": "シーズン1", "number": 1, "display_order": 0 }
```
`group_type`, `group_name`は必須。`number`, `display_order`(デフォルト0), `parent_item_id`はoptional。

**実装ファイル**: `mediavault-api/src/models/item_group.rs`

### 2. POST /items/:id/groups ハンドラ実装 🔵
**信頼性**: 🔵 *REQ-010/011・TC-010-01/TC-011-01より*

`mediavault-api/src/handlers/item_groups.rs`に`create_item_group`を実装する。パスパラメータの`item_id`を外部キーとして`item_groups`にINSERTする。

**実装ファイル**: `mediavault-api/src/handlers/item_groups.rs`

### 3. GET /items/:id/groups ハンドラ実装 🟡
**信頼性**: 🟡 *api-endpoints.md REQ-010「一覧表示」から妥当な推測*

`item_id`に紐づく`item_groups`を`display_order ASC`でソートして取得する。

**実装ファイル**: `mediavault-api/src/handlers/item_groups.rs`, `mediavault-api/src/repositories/item_group_repository.rs`

## 単体テスト要件

### テストケース1: TC-010-01 シーズングループ作成の正常動作 🔵
**Given** 既存item, `{ "group_type": "season", "group_name": "シーズン1", "number": 1 }`
**When** `POST /items/:id/groups`を呼び出す
**Then** 201でグループ（UUID付き）が返る

### テストケース2: TC-011-01 巻グループ作成の正常動作 🔵
**Given** 既存item, `{ "group_type": "volume", "group_name": "第1巻", "number": 1 }`
**When** `POST /items/:id/groups`を呼び出す
**Then** 201でグループが返る

### テストケース3: group_type不正値で400 🟡
**Given** `group_type="invalid"`
**When** `POST /items/:id/groups`を呼び出す
**Then** 400 `VALIDATION_ERROR`が返る

### テストケース4: グループ一覧のdisplay_order順取得 🟡
**Given** display_orderが2,0,1の3グループ
**When** `GET /items/:id/groups`を呼び出す
**Then** display_order 0,1,2の順で返る
