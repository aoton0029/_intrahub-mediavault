## タスク概要
タグ・カテゴリのCRUDおよびitemへの付与・削除エンドポイントを実装する。`POST /tags`, `DELETE /tags/:id`, `POST /items/:id/tags/:tag_id`, `DELETE /items/:id/tags/:tag_id`, `POST /categories`, `DELETE /categories/:id`、およびカテゴリのitem付与・削除を実装する。

## 依存タスク
- **前提タスク**: TASK-0004（マイグレーション）, TASK-0007（起動骨格）
- **後続タスク**: なし

## 完了条件
- [ ] `POST /tags`がタグ名（`name`）を受け取り、`tags`テーブルに作成する
- [ ] `name`重複時は一意制約違反を適切なエラー（409または400）にマッピングする
- [ ] `DELETE /tags/:id`がタグを削除する（`item_tags`はON DELETE CASCADEで連動削除）
- [ ] `POST /items/:id/tags/:tag_id`が`item_tags`に付与レコードを作成する
- [ ] `DELETE /items/:id/tags/:tag_id`が`item_tags`から削除する
- [ ] `POST /categories`, `DELETE /categories/:id`がタグと同様のパターンで実装される
- [ ] `item_categories`への付与・削除エンドポイントが実装される

## 実装詳細

### 1. タグCRUDハンドラ実装 🔵
**信頼性**: 🔵 *REQ-004・user-stories 2.1より*

`mediavault-api/src/handlers/tags.rs`に`create_tag`, `delete_tag`, `attach_tag_to_item`, `detach_tag_from_item`を実装する。`tags`テーブルは`name VARCHAR(100) UNIQUE`制約を持つ。

**実装ファイル**: `mediavault-api/src/handlers/tags.rs`, `mediavault-api/src/models/tag.rs`

### 2. item_tags付与・削除エンドポイント 🟡
**信頼性**: 🟡 *REQ-004「付与・削除」から妥当な推測（エンドポイント形式は未記載のため推測、api-endpoints.mdでも🟡）*

`POST /items/:id/tags/:tag_id`は`item_tags`への複合キーINSERT（既存の場合はno-opまたは409）、`DELETE /items/:id/tags/:tag_id`は複合キーでのDELETEを行う。

**実装ファイル**: `mediavault-api/src/handlers/tags.rs`

### 3. カテゴリCRUDハンドラ実装 🔵
**信頼性**: 🔵 *REQ-004より*

タグと同様のパターンで`mediavault-api/src/handlers/categories.rs`に`create_category`, `delete_category`, `attach_category_to_item`, `detach_category_from_item`を実装する。

**実装ファイル**: `mediavault-api/src/handlers/categories.rs`, `mediavault-api/src/models/category.rs`

## 単体テスト要件

### テストケース1: タグ作成の正常動作 🔵
**Given** `{ "name": "お気に入り" }`
**When** `POST /tags`を呼び出す
**Then** 201でタグ（UUID付き）が返る

### テストケース2: タグ名重複でエラー 🟡
**Given** 既存タグと同名の`name`
**When** `POST /tags`を呼び出す
**Then** 一意制約違反に対応したエラー（例: 409 `DUPLICATE_TAG_NAME`）が返る

### テストケース3: タグのitem付与・削除 🟡
**Given** 既存item, 既存tag
**When** `POST /items/:id/tags/:tag_id` → `DELETE /items/:id/tags/:tag_id`を順に呼び出す
**Then** `item_tags`にレコードが作成され、その後削除される

### テストケース4: カテゴリCRUDの正常動作 🔵
**Given** `{ "name": "本棚A" }`
**When** `POST /categories`を呼び出す
**Then** 201でカテゴリが返る
