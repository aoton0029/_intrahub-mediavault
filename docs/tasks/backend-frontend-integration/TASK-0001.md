## 実装詳細

### 1. ビルドステージ 🔵

**信頼性**: 🔵 *note.md 技術スタック（yarn, Vite 6）・アーキテクチャ設計「配信方式」より*

Node.js公式イメージ（例: `node:20-slim` 相当、既存プロジェクトのNode要件に合わせる）をベースに、`frontend/package.json`・`frontend/yarn.lock` をコピーして `yarn install --frozen-lockfile` を実行し、次いでソース一式をコピーして `yarn build` を実行する。

**実装ファイル**: `frontend/Dockerfile`

```dockerfile
FROM node:20-slim AS builder
WORKDIR /app
COPY package.json yarn.lock ./
RUN yarn install --frozen-lockfile
COPY . .
RUN yarn build
```

### 2. ランタイムステージ 🔵

**信頼性**: 🔵 *アーキテクチャ設計「配信方式：nginxで配信」より*

`nginx:alpine` 等の軽量イメージをベースに、ビルドステージの `dist/` を `/usr/share/nginx/html` にコピーし、TASK-0002で作成する `nginx.conf` を配置する。80番ポートをEXPOSEする。

**実装ファイル**: `frontend/Dockerfile`

```dockerfile
FROM nginx:alpine AS runtime
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```

### 3. Node バージョンの確認 🟡

**信頼性**: 🟡 *frontend/package.json に明記の engines 指定がない場合の妥当な推測。実装時に `frontend/package.json` の `engines` フィールドやCI設定を確認しバージョンを確定する*

`frontend/package.json` に `engines.node` 指定があればそれに合わせ、なければVite 6が要求するNode LTS（20系）を採用する。
