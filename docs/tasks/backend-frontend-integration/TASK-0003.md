## 単体テスト要件

### テストケース1: デフォルトBASE_URLが相対パスであること 🔵

**信頼性**: 🔵 *要件定義書 REQ-009・受け入れ基準 TC-003-01より*

**Given**: `VITE_API_BASE_URL` 環境変数が未設定の状態
**When**: `apiClient` がAPIリクエストを発行する
**Then**: リクエストURLが `/api/v1/...` から始まる相対パスである

**テストファイル**: `frontend/src/api/client.test.ts`（既存になければ新規作成）

```typescript
describe('apiClient BASE_URL', () => {
  it('デフォルトで相対パス /api/v1 をベースにリクエストする', async () => {
    const fetchSpy = vi.spyOn(global, 'fetch').mockResolvedValue(
      new Response(JSON.stringify({ success: true, data: {} }))
    );
    await apiClient('/items');
    expect(fetchSpy).toHaveBeenCalledWith('/api/v1/items', expect.anything());
  });
});
```

## 注意事項

- ローカル開発時（`yarn dev` 単体起動、nginx経由でない場合）に `VITE_API_BASE_URL` を設定していない開発者は、相対パス化により `http://localhost:5173/api/v1/...` へリクエストが飛ぶようになる（Viteのdevサーバープロキシは本要件のスコープ外＝REQ-405のため、未設定のままではAPI疎通しない可能性がある）。既存の開発者向けドキュメント・READMEに影響がないか確認すること
- 本タスクは統合環境（nginx経由）でのAPI疎通を前提とした変更であり、単体でのdocker compose起動確認はTASK-0006で実施する
