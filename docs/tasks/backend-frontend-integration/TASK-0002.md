## 実装詳細

### 1. リバースプロキシ設定 🔵

**信頼性**: 🔵 *要件定義書 REQ-007・データフロー図「API疎通フロー」より*

`location /api/ { proxy_pass http://backend:8080/api/; }` を設定する。`backend` はdocker-compose内のサービス名（TASK-0004で定義）で名前解決される。

**実装ファイル**: `frontend/nginx.conf`

```nginx
server {
    listen 80;
    server_name _;
    root /usr/share/nginx/html;
    index index.html;

    location /api/ {
        proxy_pass http://backend:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location / {
        try_files $uri /index.html;
    }
}
```

### 2. SPAフォールバック設定 🔵

**信頼性**: 🔵 *要件定義書 REQ-008より*

`/api/` 以外のすべてのパスに対して `try_files $uri /index.html` を適用し、React Routerによるクライアントサイドルーティングを機能させる。

**実装ファイル**: `frontend/nginx.conf`
