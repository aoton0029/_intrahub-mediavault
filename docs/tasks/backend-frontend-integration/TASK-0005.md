## 実装詳細

### 1. ルート.env.example作成 🔵

**信頼性**: 🔵 *既存 backend/.env.example・TASK-0004のdbサービス定義より*

既存の `backend/.env.example` と同等の変数（`POSTGRES_USER`/`POSTGRES_PASSWORD`/`POSTGRES_DB`/`DATABASE_URL`）をルート `.env.example` に定義する。`DATABASE_URL` のホスト部分はdocker-compose内のサービス名 `db` を使用する。

**実装ファイル**: `.env.example`

```
POSTGRES_USER=mediavault
POSTGRES_PASSWORD=changeme
POSTGRES_DB=mediavault
DATABASE_URL=postgresql://mediavault:changeme@db:5432/mediavault
```

### 2. .gitignore確認 🔵

**信頼性**: 🔵 *非機能要件 NFR-102・受け入れ基準 TC-NFR-102-01より*

ルートの `.gitignore` にルート `.env` が除外されているか確認し、含まれていなければ追記する。

**実装ファイル**: `.gitignore`
