## 実装詳細

### 1. dbサービス定義 🔵

**信頼性**: 🔵 *要件定義書 REQ-003・既存 backend/docker-compose.yml のPostgres定義より*

既存の `backend/docker-compose.yml` の `db` サービス定義（`postgres:16`、ヘルスチェック付き）を流用するが、`ports:` は設定しない（統合用のみ非公開化）。

**実装ファイル**: `docker-compose.yml`

```yaml
services:
  db:
    image: postgres:16
    restart: unless-stopped
    environment:
      POSTGRES_USER: ${POSTGRES_USER}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
      POSTGRES_DB: ${POSTGRES_DB}
    volumes:
      - mediavault_pgdata:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${POSTGRES_USER} -d ${POSTGRES_DB}"]
      interval: 5s
      timeout: 5s
      retries: 5
```

### 2. backendサービス定義 🔵

**信頼性**: 🔵 *要件定義書 REQ-002, REQ-101・既存backend/Dockerfileより*

既存の `backend/Dockerfile` をそのまま利用し、`build.context: ./backend` を指定する。`ports:` は設定しない。

**実装ファイル**: `docker-compose.yml`

```yaml
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    restart: unless-stopped
    depends_on:
      db:
        condition: service_healthy
    env_file:
      - ./backend/.env
    environment:
      DATABASE_URL: ${DATABASE_URL}
```

### 3. frontendサービス定義 🔵

**信頼性**: 🔵 *要件定義書 REQ-004, REQ-202より*

TASK-0001で作成した `frontend/Dockerfile` を利用し、ホストの80番ポートに公開する。

**実装ファイル**: `docker-compose.yml`

```yaml
  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    restart: unless-stopped
    ports:
      - "80:80"

volumes:
  mediavault_pgdata:
```

### 4. ファイル配置場所の決定 🟡
